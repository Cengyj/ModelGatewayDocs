## 这几个词分别是什么意思 {#core-terms}

### 站点地址

你在浏览器里打开官网或控制台时用的地址。就像你平时访问网页的网址。

### API Key

它像是一把“通行钥匙”。工具发请求到 ForOpenCode 时，会带上这把钥匙证明“你有权限访问”。

### Base URL / Endpoint / API Base URL

这些词经常指“工具往哪里发请求”。不同工具叫法不同，但大多数时候都是在问你“接口地址填什么”。

### `/v1`

这是接口路径的一部分。很多 OpenAI-compatible 工具会要求带上这一段。
如果工具明确提到 OpenAI-compatible、Completions、Chat Completions，通常就要特别留意这一段。

### 模型 ID

有些工具除了地址和 Key，还会要求你填写模型名字，比如 `gpt-5.4`。
这不是随便写着玩的字段，写错了通常会直接请求失败。

### 重启工具

不是刷新一下页面就算重启。很多桌面工具要完全关掉，再重新打开，新配置才会生效。

### 新开聊天验证

有些工具会在旧会话里继续沿用旧配置。所以改完后，最好新建一个会话再发测试问题。

<GlossaryHint title="一句话记忆法">
  地址告诉工具“去哪里”，Key 告诉工具“我是谁”，模型 ID 告诉工具“我要用哪个模型”，重启和新开聊天则是“让新配置真的生效”。
</GlossaryHint>

## 新手最容易踩的坑 {#common-pitfalls}

- 把官网地址和接口地址当成同一个东西随便填。
- 把文档里的“你的 API Key”当成真实值，忘了替换。
- 工具已经保存成功，但没有重启或没有新开会话。
- 看到 `Base URL`、`Endpoint`、`API URL` 等不同词，以为它们完全不是一回事。

<WindowsTip title="如果你只记一条">
  真正开始前，请把 [配置参数总表](/site-config/) 开着放在旁边。
  每次看到地址字段、Key 字段、模型字段时，回去对照一遍，能少走很多弯路。
</WindowsTip>
