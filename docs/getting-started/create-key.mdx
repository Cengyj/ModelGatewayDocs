# 创建并复制 API Key

这页只解决一件事：带你在控制台里创建一把自己的 API Key，并把它复制出来给工具使用。
后面所有工具页里要填的 `sk-` 开头密钥，都是从这里来的。

  items={[

    {href: '#check', title: '直达检查', description: '确认 Key 已经生成并复制。'},

## 你会完成什么

- 进入 ForOpenCode 控制台的 `令牌管理` 页面。
- 点击 `添加令牌`。
- 按截图填写名称、选择默认分组、数量选 `1`，然后提交。
- 在列表里复制刚创建好的 `sk-` 开头密钥。

## 如果没成功先看这里 {#fix}

<ErrorCard title="创建 API Key 最常见的问题">
  <ul>
    <li>你还没有额度，却先来创建 Key。</li>
    <li>只记住了令牌名称，没有复制真正的 `sk-` 密钥。</li>
    <li>把文档里的示例值当成真实 Key，用错了。</li>
