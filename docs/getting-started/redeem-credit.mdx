# 先兑换充值额度

如果你的账号里没有可用额度，后面就算地址和 Key 都填对了，也可能照样无法正常使用。
所以在创建 API Key 和配置工具前，先把额度准备好。

  items={[

## 你会完成什么

- 进入 ForOpenCode 控制台的 `钱包管理` 页面。
- 切到 `额度充值`。
- 输入兑换码并点击 `兑换额度`。
- 确认余额已经到账，再继续后面的创建 Key 和工具配置。

## 完成后你会看到什么 {#check}

<SuccessCard title="成功判定">
  <ul>
    <li>钱包管理页里的余额不再是原来的旧值。</li>
    <li>兑换成功后，你可以继续去创建 API Key。</li>
    <li>后面配置工具时，不会再因为账号没有额度而直接卡住。</li>
  </ul>
</SuccessCard>

## 如果没成功先看这里 {#fix}

<ErrorCard title="兑换充值最常见的问题">
  <ul>
    <li>输入的兑换码有空格、少字或多字。</li>
    <li>你打开的是别的页面，不是在 `钱包管理 > 额度充值`。</li>
    <li>兑换后没有重新看余额，误以为没到账。</li>
    <li>手里的兑换码本身已经失效或已经被用过。</li>
  </ul>
</ErrorCard>

<WindowsTip title="下一步应该去哪里">
  额度准备好后，下一步通常就是去 [创建 API Key](/getting-started/create-key)。
  有了额度和 Key，再去配置 OpenCode、OpenClaw 或 Codex 会顺很多。
</WindowsTip>
