# 先下载安装工具

在开始任何配置之前，先确认你已经安装了 **CC Switch**。
如果还没安装，不要先跳去填地址和 Key，先把工具下载好再继续。

## 下载后先做这一步

- 安装完成后，先确保你能正常打开 CC Switch。
- 能打开工具界面，再继续看后面的配置文档。
- 如果工具根本打不开，先不要填配置，先解决安装问题。
