<GlossaryHint title="这几个字段分别是什么意思">
  <ul>
    <li><strong>Base URL</strong>：OpenCode 请求模型接口的入口，这里要带 `/v1`。</li>
    <li><strong>API Key</strong>：你的 ForOpenCode 令牌，用来鉴权。</li>
    <li><strong>setCacheKey</strong>：OpenCode 额外选项，按当前实机配置填成 `true`。</li>
    <li><strong>variants</strong>：同一个模型下不同推理强度的档位。</li>
  </ul>
</GlossaryHint>

## 如果没生效先看这里 {#fix}

<ErrorCard title="OpenCode 常见失败点">
  <ul>
    <li>Base URL 少了 `/v1`，只填了 `https://www.foropencode.com`。</li>
    <li>API Key 填错、复制少了字符，或者仍然是示例文本。</li>
    <li>`setCacheKey` 没填，或值不是 `true`。</li>
    <li>模型属性里的 variants、modalities 或 attachment 漏填。</li>
    <li>保存后没有重启 OpenCode，仍然在旧进程里测试。</li>
  </ul>
</ErrorCard>

## 回退方式

- 回到 OpenCode 供应商列表，把旧供应商重新设为当前使用项。
- 如果你手动改过配置文件，先恢复备份文件，再重启 OpenCode。
- 回退后也要新开会话测试，旧会话不能作为最终判断。
