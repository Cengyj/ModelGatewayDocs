## 官方依据

<GlossaryHint title="OpenCode 官方配置机制">
  OpenCode 官方配置文档说明，配置文件可使用 `opencode.json` 或 `opencode.jsonc`，并支持 `model`、`small_model`、`provider` 等配置项。参考：[OpenCode configuration docs](https://opencode.ai/docs/config/) 和 [OpenCode providers docs](https://opencode.ai/docs/providers/)。
</GlossaryHint>

<StepChecklist title="步骤 3：合并 provider 配置" items={[
  '新增 ForOpenCode provider，不要删除原 provider。',
  'Base URL 使用 `https://www.foropencode.com/v1`。',
  '模型使用 `gpt-5.4`。',
  '按你当前 OpenCode 版本支持的字段写入 Key 或环境变量引用。',
  '保留 `setCacheKey=true` 和 variants 配置。',
]} />

```jsonc
{
  // 示例片段：请合并到你现有配置，不要整份覆盖
  "model": "foropencode/gpt-5.4",
  "provider": {
    "foropencode": {
      "name": "ForOpenCode",
      "baseURL": "https://www.foropencode.com/v1",
      "apiKey": "读取 FOROPENCODE_API_KEY 或填入你的真实 Key",
      "options": {
        "setCacheKey": true
      },
      "models": {
        "gpt-5.4": {
          "name": "gpt-5.4",
          "variants": {
            "low": {"reasoningEffort": "low"},
            "medium": {"reasoningEffort": "medium"},
            "high": {"reasoningEffort": "high"},
            "xhigh": {"reasoningEffort": "xhigh"}
          }
        }
      }
    }
  }
}
```

<WindowsTip title="为什么示例写成片段">
  OpenCode 官方配置支持 provider，但不同版本和 provider 类型的具体字段可能不同。本页不把示例当作唯一完整配置，避免你覆盖掉原配置或写入不兼容字段。
</WindowsTip>

<ErrorCard title="手动配置风险">
  <ul>
    <li>不要把本页 JSONC 片段当作整份配置直接覆盖。</li>
    <li>不要把示例 Key 原样保存。</li>
    <li>JSON 多一个逗号、少一个括号都会导致配置失效。</li>
    <li>不同 OpenCode 版本字段名可能不同，无法确认时优先使用 CC Switch。</li>
  </ul>
</ErrorCard>
