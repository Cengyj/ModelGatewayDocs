## 官方依据

<GlossaryHint title="OpenCode 官方配置机制">
  OpenCode 官方配置文档说明，配置文件可使用 `opencode.json` 或 `opencode.jsonc`，全局配置默认放在 `~/.config/opencode/opencode.json`，项目根目录也可以放 `opencode.json`，项目配置优先级更高。自定义 OpenAI-compatible provider 需要使用 `@ai-sdk/openai-compatible`，Base URL 写在 `provider.<id>.options.baseURL`。参考：[OpenCode Config](https://opencode.ai/docs/config/) 和 [OpenCode Providers](https://opencode.ai/docs/providers/)。
</GlossaryHint>

<StepChecklist title="步骤 3：合并 provider 配置" items={[
  '新增 `provider.foropencode`，不要删除原有 provider。',
  '`npm` 使用 `@ai-sdk/openai-compatible`。',
  '`options.baseURL` 使用 `https://www.foropencode.com/v1`。',
  '`options.setCacheKey` 填 `true`。',
  '如果你没有用 `/connect` 存凭据，就保留 `options.apiKey` 并填真实 Key；如果已用 `/connect`，可以删除 `apiKey` 行。',
  '顶层 `model` 写 `foropencode/gpt-5.4`，`small_model` 可先写同一个模型。',
  '模型的 `limit.context` 填 `1050000`，`limit.output` 填 `128000`。',
]} />

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "model": "foropencode/gpt-5.4",
  "small_model": "foropencode/gpt-5.4",
  "provider": {
    "foropencode": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "ForOpenCode",
      "options": {
        "baseURL": "https://www.foropencode.com/v1",
        "apiKey": "sk-你的真实Key",
        "setCacheKey": true
      },
      "models": {
        "gpt-5.4": {
          "name": "gpt-5.4",
          "limit": {
            "context": 1050000,
            "output": 128000
          }
        }
      }
    }
  }
}
```

<WindowsTip title="不要整份覆盖">
  如果你原来的 `opencode.json` 已经有 theme、agent、permission、plugin、keybinds 等配置，只把上面的 `provider.foropencode`、`model`、`small_model` 合并进去。不要为了接入 ForOpenCode 覆盖整份配置。
</WindowsTip>

<WindowsTip title="关于 apiKey">
  如果你已经通过 `/connect` 把 `foropencode` 的凭据保存到了 `~/.local/share/opencode/auth.json`，示例里的 `options.apiKey` 可以删除。若保留 `apiKey`，一定要换成你的真实 Key，不要提交到公开仓库。
</WindowsTip>

<ErrorCard title="手动配置风险">
  <ul>
    <li>不要把本页 JSONC 片段当作整份配置直接覆盖。</li>
    <li>不要把示例 Key 原样保存。</li>
    <li>如果你用 `/connect`，provider id 必须和配置里的 `foropencode` 完全一致。</li>
    <li>OpenCode 的 Base URL 字段是 `options.baseURL`，大小写不要写成 `baseUrl` 或放错层级。</li>
    <li>`limit.context` 表示最大输入上下文，`limit.output` 表示最大输出；这里分别是 `1050000` 和 `128000`。</li>
    <li>JSON 多一个逗号、少一个括号都会导致配置失效。</li>
    <li>不同 OpenCode 版本字段名可能不同，无法确认时优先使用 CC Switch。</li>
  </ul>
</ErrorCard>

<WindowsTip title="更稳的方式">
  不确定配置结构时，先使用 [OpenCode：CC Switch 配置](/tools/opencode/ccswitch)。
</WindowsTip>
