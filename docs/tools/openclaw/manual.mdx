## 官方依据

<GlossaryHint title="OpenClaw 官方入口和本页边界">
  OpenClaw 官方文档说明，配置文件默认读取 `~/.openclaw/openclaw.json`，自定义供应商通过 `models.providers` 添加，模型引用使用 `provider/model` 格式。本页只写 ForOpenCode 需要合并的字段，不要求你替换整个配置文件。参考：[OpenClaw Configuration](https://docs.openclaw.ai/gateway/configuration) 和 [Configuration Reference：Custom providers](https://docs.openclaw.ai/gateway/configuration-reference#custom-providers-and-base-urls)。
</GlossaryHint>

<StepChecklist title="步骤 2：合并 ForOpenCode provider 字段" items={[
  '在根级 `models.providers` 下新增 `foropencode`。',
  '`baseUrl` 填 `https://www.foropencode.com/v1`。',
  '`api` 填 `openai-completions`，对应 OpenAI Chat Completions 兼容接口。',
  '`apiKey` 建议先写 `${FOROPENCODE_API_KEY}`，把真实 Key 放进环境变量或 `~/.openclaw/.env`。',
  '在 `models.providers.foropencode.models` 数组里添加 `gpt-5.4`。',
]} />

```jsonc
{
  // 如果原文件已经有 env，就只新增这一行；也可以把 Key 写到 ~/.openclaw/.env
  env: {
    FOROPENCODE_API_KEY: "sk-你的真实Key"
  },

  models: {
    mode: "merge",
    providers: {
      foropencode: {
        baseUrl: "https://www.foropencode.com/v1",
        api: "openai-completions",
        auth: "api-key",
        apiKey: "${FOROPENCODE_API_KEY}",
        models: [
          {
            id: "gpt-5.4",
            name: "gpt-5.4",
            reasoning: true,
            input: ["text", "image"],
            contextWindow: 128000,
            maxTokens: 32000
          }
        ]
      }
    }
  },

  agents: {
    defaults: {
      model: {
        primary: "foropencode/gpt-5.4"
      },
      models: {
        "foropencode/gpt-5.4": {
          alias: "ForOpenCode GPT-5.4"
        }
      }
    }
  }
}
```

<WindowsTip title="不要整份覆盖">
  上面是要合并进去的片段。你的 `openclaw.json` 里可能已经有 `channels`、`gateway`、`agents`、`tools` 等配置，必须保留。重复字段时只合并对应子字段，例如把 `foropencode` 加到已有的 `models.providers` 里。
</WindowsTip>

<ErrorCard title="手动配置风险">
  <ul>
    <li>OpenClaw 会严格校验配置。未知字段、类型错误或 JSON 语法错误可能导致 gateway 拒绝启动。</li>
    <li>`api` 不是显示名称，而是请求适配器；ForOpenCode 这里使用 `openai-completions`。</li>
    <li>`baseUrl` 必须带 `/v1`，否则 OpenAI 兼容请求路径可能不对。</li>
    <li>把真实 Key 写进项目级配置时，注意不要提交到公开仓库。</li>
    <li>旧聊天可能不会刷新模型，必须新开聊天验证。</li>
  </ul>
</ErrorCard>
