## 官方依据

<GlossaryHint title="OpenClaw 官方入口和本页边界">
  OpenClaw 官方仓库提供 gateway 命令和配置文件相关入口，但不同版本的 provider 字段可能变化。本页只固定 ForOpenCode 必填值：协议、端点、Key、模型、默认供应商和重启动作；不编造完整配置文件路径或结构。参考：[OpenClaw GitHub](https://github.com/CodePhiliaX/OpenClaw)。
</GlossaryHint>

## 跟着做

<StepChecklist title="步骤 1：备份并确认配置入口" items={[
  '关闭或暂停正在使用的 OpenClaw 会话。',
  '找到当前版本的 providers 或供应商配置区域。',
  '复制一份原配置，便于回退。',
  '不要覆盖原来能用的供应商。',
]} />

<StepChecklist title="步骤 2：新增 ForOpenCode 供应商" items={[
  '新增供应商标识，例如 `foropencode`。',
  '供应商名称建议写 `ForOpenCode`。',
  '协议使用 `OpenAI Completions`。',
  '端点使用 `https://www.foropencode.com/v1`。',
  'Key 使用自己的真实 Key，或使用当前版本支持的环境变量引用方式。',
]} />

<StepChecklist title="步骤 3：添加模型并设为默认" items={[
  '模型 ID 使用 `gpt-5.4`。',
  '显示名称也建议写 `gpt-5.4`。',
  '确认模型挂在 ForOpenCode 供应商下。',
  '把 ForOpenCode 设为默认供应商。',
]} />

<StepChecklist title="步骤 4：按你的平台重启 gateway 并验证" items={[
  '保存配置。',
  '执行 `openclaw gateway restart`。',
  '重新打开 OpenClaw。',
  '新开聊天验证，不要用旧聊天判断。',
]} />
