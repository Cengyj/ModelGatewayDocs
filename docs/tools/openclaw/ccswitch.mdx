## 如果没生效先看这里 {#fix}

<ErrorCard title="OpenClaw 常见失败点">
  <ul>
    <li>API 协议没有选 `OpenAI Completions`。</li>
    <li>API 端点少了 `/v1`。</li>
    <li>没有把 `foropencode` 设为默认供应商。</li>
    <li>保存后没有执行 `openclaw gateway restart`。</li>
    <li>直接在旧聊天里测试，误以为配置没生效。</li>
  </ul>
</ErrorCard>

## 回退方式

- 回到供应商页面，把旧供应商重新设为默认。
- 再执行一次 `openclaw gateway restart`。
- 新开聊天验证旧配置是否恢复。
