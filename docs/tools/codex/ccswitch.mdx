## 如果没生效先看这里 {#fix}

<ErrorCard title="最常见失败点"><ul><li>API 请求地址少了 `/v1`。</li><li>模型名称不是 `gpt-5.4`，或字段里还留着旧值。</li><li>API Key 不是你自己控制台里生成的真实密钥。</li><li>保存后没有点击“启用”。</li><li>启用后没有重启终端或 VS Code。</li></ul></ErrorCard>
