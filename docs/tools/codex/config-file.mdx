## 文件分工

<GlossaryHint title="这次要改两个文件">
  <ul>
    <li><code>{'~/.codex/config.toml'}</code>：写默认模型、provider 名称、Base URL 和请求协议。</li>
    <li><code>{'~/.codex/auth.json'}</code>：写 <code>OPENAI_API_KEY</code>，也就是你从 ForOpenCode 控制台复制的真实 Key。</li>
  </ul>
</GlossaryHint>

<WindowsTip title="本页不再使用环境变量方式">
  现在手动配置页按 <code>auth.json</code> 保存 Key。不要同时照着旧环境变量教程和本页混用。
</WindowsTip>

## 跟着做

<StepChecklist title="步骤 1：找到并备份两个文件" items={[
  '打开用户目录下的 `.codex` 文件夹。',
  '找到 `config.toml`；如果不存在，可以新建这个文件。',
  '找到 `auth.json`；如果不存在，可以新建这个文件。',
  '修改前分别复制备份，例如 `config.toml.bak` 和 `auth.json.bak`。',
  '确认备份可恢复后，再继续修改。',
]} />

<PlatformCommandTabs
  title="选择你的平台：打开配置文件"
  description="如果 .codex 文件夹或文件不存在，先创建再打开。"
  commands={[
    {label: 'Windows PowerShell', code: 'New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\\.codex" | Out-Null\nnotepad "$env:USERPROFILE\\.codex\\config.toml"\nnotepad "$env:USERPROFILE\\.codex\\auth.json"', note: '`~` 在 Windows 上对应你的用户目录。'},
    {label: 'macOS zsh', code: 'mkdir -p ~/.codex\nopen -e ~/.codex/config.toml\nopen -e ~/.codex/auth.json', note: '使用系统文本编辑器打开；也可以换成你常用编辑器。'},
    {label: 'Linux bash', code: 'mkdir -p ~/.codex\nnano ~/.codex/config.toml\nnano ~/.codex/auth.json', note: '如果没有 nano，可改用 vim、code 或其他编辑器。'},
  ]}
/>

<StepChecklist title="步骤 2：修改 config.toml" items={[
  '顶层 `model` 写你要默认使用的模型，第一次建议先用 `gpt-5.4` 跑通。',
  '顶层 `model_provider` 写 `custom`。',
  '在 `[model_providers.custom]` 下写入 provider 名称、Base URL、请求协议和认证方式。',
  '`base_url` 必须带 `/v1`。',
  '`requires_openai_auth = true` 表示 Key 从 `auth.json` 里的 `OPENAI_API_KEY` 读取。',
]} />

```toml
model_provider = "custom"
model = "gpt-5.4"
disable_response_storage = true

[model_providers.custom]
name = "custom"
wire_api = "responses"
requires_openai_auth = true
base_url = "https://foropencode.com/v1"
```

<StepChecklist title="步骤 3：修改 auth.json" items={[
  '打开 `~/.codex/auth.json`。',
  '把 `OPENAI_API_KEY` 的值改成你从 ForOpenCode 控制台复制的真实 Key。',
  'JSON 必须使用英文双引号。',
  '最后一行不要加多余逗号。',
]} />

```json
{
  "OPENAI_API_KEY": "你的真实 ForOpenCode API Key"
}
```

<WindowsTip title="不要把示例 Key 原样保存">
  上面的 <code>你的真实 ForOpenCode API Key</code> 只是占位文字，必须换成你自己的真实 Key。不要把真实 Key 发到公开聊天或截图里。
</WindowsTip>

<StepChecklist title="步骤 4：重启 Codex 并新开会话" items={[

## 成功和失败判断

<SuccessCard title="成功判定">
  <ul>
    <li>新会话可以正常回复。</li>
    <li>不再出现找不到 Key、401、地址不可达等错误。</li>
    <li>需要回退时，恢复 <code>config.toml.bak</code> 和 <code>auth.json.bak</code> 并重启即可。</li>
  </ul>
</SuccessCard>

<ErrorCard title="常见失败点">
  <ul>
    <li><code>auth.json</code> 里没有 <code>OPENAI_API_KEY</code>，或者 Key 复制不完整。</li>
    <li><code>auth.json</code> 不是合法 JSON，例如用了中文引号或末尾多了逗号。</li>
    <li><code>config.toml</code> 里的 <code>base_url</code> 少了 <code>/v1</code>。</li>
    <li><code>model_provider</code> 和 <code>[model_providers.custom]</code> 的名字不一致。</li>
    <li>改完配置后没有重启终端、VS Code 或 Codex。</li>
  </ul>
</ErrorCard>

<WindowsTip title="不确定就不要硬改">
  如果你看不懂 TOML 或 JSON，直接使用 [Codex：CC Switch 配置](/tools/codex/ccswitch) 更安全。
</WindowsTip>
