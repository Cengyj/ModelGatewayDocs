# PC 电脑使用 gpt-image-2

这页适合在电脑上用 Cherry Studio 生图。先选择导入方式：可以从 ForOpenCode 网站一键导入，也可以在 Cherry Studio 里手动添加 `New API`。接入完成后，再把 `gpt-image-2` 加进 `New API`，最后到“绘画”页选择模型开始用。

  <span className="guide-status-pill">无需登录：跳过引导</span>
  <span className="guide-status-pill">关键：模型端点类型要设对</span>
</div>

</WindowsTip>

## 配好后你会看到什么 {#check}

<SuccessCard title="成功判断">
  <ul>
    <li>Cherry Studio 里已经有 `New API` 这条服务商配置。</li>
    <li>模型列表里能看到并选中 `gpt-image-2`。</li>
    <li>进入“绘画”页后，可以正常文生图，或切到“编辑”模式做图生图。</li>
  </ul>
</SuccessCard>

## 如果没成功先看这里 {#fix}

<ErrorCard title="Cherry Studio 端最常见的失败点">
  <ul>
    <li>令牌没有启用，或者带入 Cherry Studio 的不是正确 API Key。</li>
    <li>`New API` 的 API 地址不对，导致模型列表拉不出来。</li>
    <li>只添加了服务商，但没有把 `gpt-image-2` 加进模型列表。</li>
    <li>模型编辑窗口里的端点类型没有改成图像生成对应端点。</li>
    <li>已经接好了，但打开的是聊天页，不是“绘画”页。</li>
  </ul>
</ErrorCard>

</WindowsTip>
