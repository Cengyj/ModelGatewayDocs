# PC 电脑使用 gpt-image-2

这页按实际操作顺序来：先创建并复制 ForOpenCode 令牌，再把 Cherry Studio 的 `New API` 接上，最后配置图片模型并进入“绘画”或“话题”页使用。新手建议先走“绘画”页，那里直接选择 `gpt-image-2`。

## 添加并配置图片模型 {#model}

<StepChecklist
  title="步骤 3：添加 gpt-image-2 并设置端点类型"
  items={[
    '在 `New API` 模型区域搜索 `gpt`，把需要的模型添加进来。',
    '绘画页至少添加 `gpt-image-2`。',
    '如果你还要在“话题/聊天”页按尺寸生图，可以添加 `gpt-draw-1024x1536`、`gpt-draw-2048x2048`、`gpt-draw-3840x2160` 等 `gpt-draw-*` 模型。',
    '点击 `gpt-image-2` 右侧设置按钮，展开“更多设置”。',
    '把 `gpt-image-2` 的端点类型设置为 `图像生成(OpenAI)`，然后保存。',
    '`gpt-draw-*` 模型按截图保持对应的 OpenAI 类型和模型标签，保存后再使用。',
  ]}
>
  这里最容易漏的是端点类型。`gpt-image-2` 没有设成图像生成端点时，绘画页通常会找不到模型或请求失败。
</StepChecklist>

## 话题页选择 gpt-draw 模型 {#chat}

<StepChecklist
  title="步骤 5：如果在话题/聊天页生图，选择 gpt-draw-*"
  items={[

  ]}
>
  注意：`gpt-image-2` 只在“绘画”页直接选择。话题/聊天页请使用 `gpt-draw-*` 这类带尺寸的模型。
</StepChecklist>

## 配好后你会看到什么 {#check}

<SuccessCard title="成功判断">
  <ul>
    <li>Cherry Studio 的 API 服务器里已经有 <code>New API</code> 这条配置。</li>
    <li><code>New API</code> 的 API 地址是 <code>https://www.foropencode.com</code>。</li>
    <li>模型列表里能看到 <code>gpt-image-2</code>，并且端点类型已设为 <code>图像生成(OpenAI)</code>。</li>
    <li>进入“绘画”页后，可以选择 <code>New API + gpt-image-2</code>。</li>
    <li>如果使用“话题/聊天”页，可以选择 <code>gpt-draw-* | New API</code>。</li>
  </ul>
</SuccessCard>

## 如果没成功先看这里 {#fix}

<ErrorCard title="获取模型列表失败或模型数量为 0">
  <ul>
    <li>确认令牌来自 ForOpenCode 控制台，并且没有少复制字符。</li>
    <li>确认 <code>New API</code> 的 API 地址是 <code>https://www.foropencode.com</code>，不是网页端外部连接用的 <code>https://foropencode.com/v1</code>。</li>
    <li>确认 <code>New API</code> 右上角开关已经打开。</li>
    <li>点过“检测”后再点“获取模型列表”，失败时重新粘贴令牌再试一次。</li>
  </ul>
</ErrorCard>

<ErrorCard title="绘画页找不到 gpt-image-2">
  <ul>
    <li>回到 <code>New API</code> 模型列表，确认已经添加 <code>gpt-image-2</code>。</li>
    <li>点击 <code>gpt-image-2</code> 右侧设置按钮，确认端点类型是 <code>图像生成(OpenAI)</code>。</li>
    <li>保存后关闭绘画页再重新打开一次。</li>
    <li>如果你在“话题/聊天”页找模型，请改选 <code>gpt-draw-*</code>，不要在这里找 <code>gpt-image-2</code>。</li>
  </ul>
</ErrorCard>

<ErrorCard title="一键导入没有唤起 Cherry Studio">
  <ul>
    <li>先手动打开 Cherry Studio，再回到浏览器重试。</li>
    <li>检查浏览器是否拦截了外部应用打开提示。</li>
    <li>如果仍然无法唤起，切到本页“手动配置”按 `API 密钥` 和 `API 地址` 填写。</li>
  </ul>
</ErrorCard>
