# 网页端使用 gpt-image-2

这页适合直接在浏览器里的 Open WebUI 生图。流程是先创建 ForOpenCode 令牌，再进入 Open WebUI 网页端，添加一个 OpenAI 兼容的外部连接，最后在模型列表里选择 `gpt-image-2` 或开启“图像生成”工具。

<StepChecklist
  title="步骤 1：创建并复制令牌"

## 选择模型并开启图像生成 {#use}

<StepChecklist
  title="步骤 5：选择 gpt-image-2 或开启图像生成"
  items={[
    '外部连接保存成功后，关闭设置窗口回到首页。',
    '点击左上角模型名称下拉。',
    '如果列表中已显示 `gpt-image-2`，直接选择它作为网页端生图模型。',
    '如果只看到聊天模型，可以选择 `gpt-5.5`、`gpt-5.5-mini` 或 `gpt-5.4-mini`。',
    '点击输入框左侧扩展图标，开启“图像生成”。',
    '按需要设置分辨率、质量和背景，输入需求后发送。',
  ]}
>
  直接选 `gpt-image-2` 是网页端生图入口；选择聊天模型再开启“图像生成”时，图片生成也会走 `gpt-image-2`。
</StepChecklist>

<WindowsTip title="模型该选哪一个">
  <ul>
    <li>优先选择网页端生图模型：`gpt-image-2`。</li>
    <li>推荐聊天/提示词优化模型：`gpt-5.5`、`gpt-5.5-mini`、`gpt-5.4-mini`。</li>
    <li>如果模型列表里没有 `gpt-image-2`，先确认外部连接已启用，并重新保存或刷新模型列表。</li>
  </ul>
</WindowsTip>

## 常见问题 {#fix}

<ErrorCard title="提示 Image generation requires your own API key">
  <ul>
    <li>先检查外部连接 URL 是否正好是 `https://foropencode.com/v1`。</li>
    <li>确认认证方式是“密钥（Bearer）”，不是空认证或其他方式。</li>
    <li>确认 API 密钥来自 ForOpenCode 令牌管理页面，且没有少复制字符。</li>
    <li>确认连接右侧开关是开启状态，并且输入框工具菜单里已开启“图像生成”。</li>
  </ul>
</ErrorCard>

<ErrorCard title="模型列表里看不到 gpt-image-2">
  <ul>
    <li>先保存外部连接，再刷新网页或重新打开模型下拉。</li>
    <li>如果“模型 ID”手动填错，先清空，让 Open WebUI 自动读取 `/v1/models`。</li>
    <li>回到令牌管理页面确认令牌启用，并且没有限制掉图片模型。</li>
  </ul>
</ErrorCard>

<SuccessCard title="最终检查清单">
  <ul>
    <li>已创建并复制 ForOpenCode 令牌。</li>
    <li>已登录 Open WebUI 网页端。</li>
    <li>外部连接 URL 是 `https://foropencode.com/v1`。</li>
    <li>认证方式是“密钥（Bearer）”，连接开关已开启。</li>
    <li>模型列表可选择 `gpt-image-2`，或已在聊天模型下开启“图像生成”。</li>
  </ul>
</SuccessCard>
