  OpenCode、OpenClaw、Codex 多数按 OpenAI-compatible `/v1` 地址接入；但 Claude Code 当前实机配置页要求的是服务端点根地址。本页以现有实机截图为准，所以填写 `https://www.foropencode.com`。
</GlossaryHint>

## 如果没生效先看这里 {#fix}

<ErrorCard title="Claude Code 常见失败点">
  <ul>
    <li>把请求地址错填成 `/v1` 地址。</li>
    <li>API Key 不是自己的真实密钥，或者复制时少了字符。</li>
    <li>保存后没有启用，列表里还不是“使用中”。</li>
    <li>启用后没有重启终端，还在旧进程里测试。</li>
    <li>把左侧档位标签误认为真实模型名，忽略了右侧的 `gpt-5.4-*`。</li>
  </ul>
</ErrorCard>

## 回退方式

- 回到 Claude Code 配置列表，把旧配置重新设为“使用中”。
- 重启终端，再新开会话测试。
- 不要一边使用旧 Key，一边保留新地址，这样最难排查。
