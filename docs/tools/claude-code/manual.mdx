## 官方依据

<GlossaryHint title="Claude Code 官方配置机制">
  Anthropic Claude Code 官方文档说明，Claude Code 支持通过用户级、项目级和本地 settings 文件配置，也支持环境变量；环境变量可用于 API key、base URL 等运行时配置。本页保留官方配置机制，但 ForOpenCode 的具体地址按本站实机截图：根地址。参考：[Claude Code settings](https://docs.anthropic.com/en/docs/claude-code/settings) 与 [Claude Code environment variables](https://docs.anthropic.com/en/docs/claude-code/settings#environment-variables)。
</GlossaryHint>

<ErrorCard title="手动配置风险">
  <ul>
    <li>不要把其他工具的 `/v1` 地址照搬到 Claude Code。</li>
    <li>旧终端不会自动刷新新配置。</li>
    <li>settings 文件层级可能覆盖彼此，项目级配置可能覆盖用户级配置。</li>
    <li>如果你无法确认配置位置和优先级，请使用 CC Switch 配置方式。</li>
  </ul>
</ErrorCard>
