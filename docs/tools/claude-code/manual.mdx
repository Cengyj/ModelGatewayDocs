## 官方依据

<GlossaryHint title="Claude Code 官方配置机制">
  Claude Code 支持通过 settings 文件写入 `env` 配置。ForOpenCode 接入 Claude Code 时填写根地址 `https://foropencode.com/`，不要照搬 OpenCode、OpenClaw、Codex 等工具常用的 `/v1` 地址。
</GlossaryHint>

## 跟着做

<StepChecklist title="步骤 1：找到并备份 settings.json" items={[
  '先关闭正在运行的 Claude Code。',
  '找到你当前使用的 Claude Code `settings.json`。',
  '常见位置包括用户级 settings、项目级 `.claude/settings.json` 或本地 `.claude/settings.local.json`，以你当前实际使用的文件为准。',
  '修改前复制一份备份，确认能回退后再继续。',
]} />

<StepChecklist title="步骤 2：写入 env 配置" items={[
  '把 `ANTHROPIC_AUTH_TOKEN` 改成你自己的 ForOpenCode API Key。',
  '把 `ANTHROPIC_BASE_URL` 填为 `https://foropencode.com/`。',
  '确认地址末尾可以保留 `/`，但不要写成 `/v1`。',
  '如果这是项目级配置，确认不会把真实 Key 提交到公开仓库。',
]} />

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "sk-你的真实Key",
    "ANTHROPIC_BASE_URL": "https://foropencode.com/"
  },
  "includeCoAuthoredBy": false
}
```

<WindowsTip title="如果原文件已有其他配置">
  不要整份覆盖。保留原有字段，只把上面的 `env` 和 `includeCoAuthoredBy` 合并进去；如果原来已经有 `env`，就在原 `env` 里新增或替换这两个变量。
</WindowsTip>

<ErrorCard title="手动配置风险">
  <ul>
    <li>不要把其他工具的 `/v1` 地址照搬到 Claude Code。</li>
    <li>旧终端或旧 Claude Code 会话不会自动刷新新配置。</li>
    <li>settings 文件层级可能覆盖彼此，项目级配置可能覆盖用户级配置。</li>
    <li>如果你无法确认配置位置和优先级，请使用 CC Switch 配置方式。</li>
  </ul>
</ErrorCard>

<WindowsTip title="更稳的方式">
  如果不确定手动配置方式，使用 [Claude Code：CC Switch 配置](/tools/claude-code/ccswitch)。
</WindowsTip>
