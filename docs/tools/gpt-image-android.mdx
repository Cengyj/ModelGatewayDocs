# 安卓手机使用 gpt-image-2

这页适合在安卓手机上直接通过聊天页生图。和 PC 端不一样，安卓端重点不是进入“绘画页”，而是把 OpenAI 供应商、`Response API`、模型输入输出模式和内置图像生成工具都配置好。

## 配好后你会看到什么 {#check}

<SuccessCard title="成功判断">
  <ul>
    <li>供应商页里 OpenAI 配置已经启用，`Response API` 也是打开状态。</li>
    <li>模型列表里能看到并选中 `gpt-image-2`。</li>
    <li>模型编辑页已允许文本、图片输入，并把输出模式设为图片。</li>

  </ul>
</SuccessCard>

## 如果没成功先看这里 {#fix}

<ErrorCard title="安卓端最常见的失败点">
  <ul>
    <li>`API Base URL` 没带 `/v1`，或者域名填错。</li>
    <li>`Response API (/responses)` 没打开。</li>
    <li>模型页已经获取成功，但没有把 `gpt-image-2` 真正加进当前配置。</li>
    <li>模型编辑页里的输入输出模式没有配成图片生成所需模式。</li>
    <li>内置“图像生成”工具没打开，就直接回聊天页测试。</li>
  </ul>
</ErrorCard>

<WindowsTip title="什么时候该看 PC 那一页">

</WindowsTip>
