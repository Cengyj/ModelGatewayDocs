## 先分清 3 种地址 {#addresses}

<div className="guide-table">

| 名称 | 作用 | 什么时候用 | 当前值 |
| --- | --- | --- | --- |
| 站点首页地址 | 浏览器里打开官网、登录控制台 | 打开网页、查看令牌、找控制台入口 | `https://www.foropencode.com/` |
| API 根地址 | 某些工具的 Base URL / Endpoint / Provider URL | 工具页面明确让你填“服务地址”但没有要求 OpenAI 标准路径时 | `https://www.foropencode.com/` |
| API `/v1` 地址 | OpenAI-compatible 接口入口 | 工具要求 OpenAI-compatible、`/v1`、Completions、Chat Completions 时 | `https://www.foropencode.com/v1` |

</div>

<GlossaryHint title="最容易混淆的地方">
  `https://www.foropencode.com/` 和 `https://www.foropencode.com/v1` 不是随便二选一。
  前者是根地址，后者是带 OpenAI-compatible 路径的接口地址。
  工具页如果明确要求 OpenAI 协议或 `/v1`，就不要只填根地址。
</GlossaryHint>

## 当前项目已确认的填写方式 {#tool-rules}

<div className="guide-table">

| 工具 | 地址字段怎么填 | Key 从哪里来 | 额外注意 |
| --- | --- | --- | --- |
| OpenCode | 按当前实机配置填写 `/v1` 地址 | ForOpenCode 控制台 > 令牌管理 | 接口格式选 `OpenAI Compatible`，并在列表里再点一次“添加” |
| OpenClaw | 必须填写 `/v1` 地址 | ForOpenCode 控制台 > 令牌管理 | API 协议选 `OpenAI Completions` |
| Codex | 按当前实机配置填写 `/v1` 地址 | ForOpenCode 控制台 > 令牌管理 | 模型填 `gpt-5.4`，添加后还要点“启用”并重启 CLI 或 VS Code |
| Claude Code | 按当前实机配置填写根地址 | ForOpenCode 控制台 > 令牌管理 | 填 `https://www.foropencode.com`，不要加 `/v1`；如需 GPT 5.4，按任务选择 `gpt-5.4-low`、`gpt-5.4-medium` 或 `gpt-5.4-high` |

</div>

## 成功判定标准 {#success-check}

<SuccessCard title="不是“能保存”就算成功">
  至少满足下面 3 条，才算真的接上 ForOpenCode：
  <ul>
    <li>地址和 Key 已保存。</li>
    <li>重启工具或新开会话后，仍然保留新配置。</li>
    <li>发送一个最小测试问题时，能够正常返回，不再报连接或鉴权错误。</li>
  </ul>
</SuccessCard>

<WindowsTip title="Windows 用户的小提醒">
  如果某个工具提示你“重启应用后生效”，请真的关掉再重新打开。
  很多“明明保存了却没效果”的情况，最后都是旧进程还在吃旧配置。
</WindowsTip>
