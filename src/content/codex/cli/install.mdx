> Codex CLI 与 IDE 扩展等共用 `CODEX_HOME`（默认 `~/.codex/`）下的配置；Codex App 的配置共享范围以官方文档当前说明为准。App 的安装见 [Codex 桌面版 · 安装](/codex/desktop/install)。

---

## 系统要求

<Callout type="info" title="环境要求">
- **npm 安装**：需要本机已有受支持的 Node.js 与 npm；独立二进制和 Homebrew 不依赖全局 npm
- **Git**：建议安装，用于仓库上下文与变更检查
- **操作系统**：按 [OpenAI 官方 Releases](https://github.com/openai/codex/releases/latest) 提供的当前平台构建选择；Windows 也可使用官方支持的原生/WSL 工作流
</Callout>

---

## 准备 Git（建议）

Codex 可在普通目录运行，但 Git 能提供仓库上下文和变更检查。Windows 可从 [Git for Windows](https://git-scm.com/install/windows) 安装；其它系统先确认终端能运行 `git`：

```bash
git --version
node --version   # 仅 npm 安装方式需要
```

## 安装

<Tabs defaultValue="official">
  <Tab label="官方脚本（macOS / Linux）" value="official">
    OpenAI 官方仓库当前 Quickstart 提供以下安装器；它默认从 `releases.openai.com/codex` 获取发布内容，并在必要时回退到官方 GitHub Releases：

    <Callout type="warning">执行前先查看 [openai/codex 官方仓库](https://github.com/openai/codex) 的当前安装说明，确认脚本域名、证书和内容。Windows 官方示例会调整当前 PowerShell 进程的 ExecutionPolicy，本站不直接复制该远程执行命令；请在官方说明中审阅后再决定。</Callout>

    ```bash
    curl -fsSL https://chatgpt.com/codex/install.sh | sh
    ```
  </Tab>
  <Tab label="npm（全平台）" value="npm">
    ```bash
    npm install -g @openai/codex
    ```

    升级到最新版：

    ```bash
    npm install -g @openai/codex@latest
    ```
  </Tab>
  <Tab label="Homebrew (macOS)" value="brew">
    ```bash
    brew install --cask codex
    ```
  </Tab>
  <Tab label="独立二进制 / Windows" value="release">
    前往 [OpenAI 官方 GitHub Releases（github.com/openai/codex）](https://github.com/openai/codex/releases/latest)，选择与操作系统和 CPU 架构匹配的发布资产。本站不托管或重新打包这些文件。

    下载后先核对发布方为 `openai/codex`；若系统提示签名或发布方异常，请停止运行并回到官方发布页核实。
  </Tab>
</Tabs>

## 常见问题

<Callout type="warning" title="安装或下载失败？">
确认安装入口来自 `chatgpt.com/codex`、`releases.openai.com/codex`、npm 的 `@openai/codex` 或 `github.com/openai/codex`。再检查 DNS、系统时间、企业防火墙与已获授权的代理设置；不要关闭 SmartScreen、Gatekeeper、签名或 TLS 校验。
</Callout>
