> 还没装 CC Switch？先看 [CC Switch 安装](/cc-switch)。

<Callout type="warning" title="第三方工具与第三方网关">
CC Switch 不是 OpenAI 产品，`foropencode.com` 也不是 OpenAI API。使用前备份 `~/.codex/`，确认 CC Switch 当前版本支持你的 Codex 版本，并核对最终 Base URL、凭据存储、数据处理与计费主体。
</Callout>

<Callout type="warning">Codex 的 Base URL **必须**带 `/v1` 后缀，和 Claude Code 反着。漏了会 404。</Callout>

## 配置步骤

<Walkthrough title="CC Switch · 配置 Codex（CLI / App 通用）">
  <Frame step="1" title="选中 Codex 图标，点击添加"
    image="/img/cc-switch/cc-switch-codex-main-add.png"
    imageAlt="CC Switch 主界面：选中 Codex 图标，点右上角添加按钮">
    打开 CC Switch，顶部工具栏按名称选中 **Codex 图标**，点右上角 **＋** 按钮新建一项；不要依赖图标排列位置。

    **Codex CLI 和 Codex App 共享 `~/.codex/config.toml`**——只配一次，两者都生效。
  </Frame>

  <Frame step="2" title="填写供应商信息"
    image="/img/cc-switch/cc-switch-codex-provider-form.png"
    imageAlt="添加新供应商表单：名称、API Key、请求地址（带 /v1）">
    弹出「添加新供应商」表单，按顺序填写：

    - **供应商名称**：随便取，如 `for`
    - **API Key**：你的 Codex 分组对应 Key（`sk-xxx`）
    - **API 请求地址**：点击右侧图标复制后粘贴

    <CommandTable header={false} rows={[
      { cmd: 'https://foropencode.com/v1', desc: 'Codex 必须带 /v1，和 Claude Code 反着' },
    ]} />

    <Callout type="warning">**暂不要点「添加」**，先进行下一步勾选 Goal mode 设置。</Callout>
  </Frame>

  <Frame step="3" title="启用 Goal mode 与通用配置，再点添加"
    image="/img/cc-switch/cc-switch-codex-goalmode.png"
    imageAlt="勾选启用 Goal mode 和写入通用配置的表单截图（截图中的认证字段为旧界面示例，按当前版本与网关要求选择）">
    在表单下方继续勾选：

    - ✅ **启用 Goal mode**
    - ✅ **写入通用配置**
    - 若表单出现认证字段，按 CC Switch 当前官方说明和网关实际鉴权要求选择，不要根据旧截图强制填写

    设置完毕后，点右下角 **＋ 添加**。CC Switch 可能写入 `~/.codex/config.toml` 和凭据存储；这些文件含敏感信息，不能上传仓库或排障网站。
  </Frame>

  <Frame step="4" title="确认配置添加成功"
    image="/img/cc-switch/cc-switch-codex-active-status.png"
    imageAlt="主界面配置行显示名称和 Base URL，绿色「使用中」按钮常驻，说明配置已生效">
    回到主界面，配置行显示供应商名称和 Base URL，绿色 **「✓ 使用中」** 按钮常驻即表示配置已成功写入并生效。

    - **CLI**：重启终端，下一次跑 `codex` 即生效
    - **Codex App**：**完全退出**（菜单栏图标也要关），再启动
  </Frame>
</Walkthrough>

## 可用模型

OpenAI 当前 Codex 默认 Power 设置使用 `gpt-5.6-sol`，但这不代表 foropencode 网关已经提供该模型。CC Switch 表单中应以网关实际模型列表为准，不手填未经确认的上下文或最大输出。`gpt-5.2`、`gpt-5.3-codex` 对 ChatGPT 登录的 Codex 已弃用；API 和第三方 provider 的可用性另行核对。

---

## 推理深度

通过 `model_reasoning_effort` 控制（CC Switch 表单里有这一项，等价于在 `~/.codex/config.toml` 中设置）：

| 值 | 备注 |
| --- | --- |
| `minimal` | 最低推理档位；是否可用取决于模型 |
| `low` | 较低推理档位 |
| `medium` | 中等推理档位 |
| `high` | 较高推理档位 |
| `xhigh` | 仅 Responses API 路径下、且模型支持时可用 |

---

## 配置写到哪

CC Switch 将配置写入 `~/.codex/config.toml`（CLI 与 Codex App 共用同一文件）：

| 平台 | 路径 |
| --- | --- |
| macOS / Linux | `~/.codex/config.toml` |
| Windows | `%USERPROFILE%\.codex\config.toml` |
