# Codex 桌面版 · 安装

旧版页面把 Codex 描述成“ChatGPT 桌面客户端内置工作区”，并建议使用“临时账号”。当前 Codex CLI 提供独立的 `codex app` 命令来启动桌面 App，缺少 App 时会打开安装流程；账户应使用你有权使用的 ChatGPT 工作区或官方 API Key，不应使用来源不明的临时账号。

---

## 启动或安装

```bash
# 在当前目录打开 Codex App
codex app

# 打开指定工作区
codex app /path/to/project
```

<Callout type="warning" title="保持官方安装流程">
OpenAI 官方仓库提供 `codex app` 和 Codex App 页面作为入口。不要改用未知镜像、重打包安装器或无法识别最终域名的下载链接；本站不托管或代理 Codex App 安装包。
</Callout>

---

## 登录与配置

Codex 本地工作支持 ChatGPT 登录或 OpenAI API Key 登录。通过 API Key 登录时，部分依赖 ChatGPT workspace 或云服务的功能可能不可用。使用第三方 custom provider 时，请阅读 [Codex 手动配置](/codex/manual)，并明确第三方网关的数据、计费和模型边界。

CLI、IDE 扩展和桌面 App 共享 `~/.codex/config.toml` 配置层。修改 provider、模型或权限后，新建会话核对实际值；不要把“共享配置”理解为第三方请求绝不会触达 OpenAI，实际数据流由当前登录方式、provider 和功能共同决定。

---

## 验证

- `codex app` 由官方 `openai/codex` CLI 提供
- 安装流程使用默认官方地址，没有通过第三方镜像或 `--download-url` 覆盖
- App 显示的工作区、登录方式、provider 与你的预期一致
- 保持默认沙箱和审批设置，按任务需要最小化放宽
