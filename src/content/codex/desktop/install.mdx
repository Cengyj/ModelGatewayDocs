# Codex 桌面版 · 安装

> Codex App 是 ChatGPT 桌面客户端里内置的代理形态，与 CLI **共享** `~/.codex/config.toml`。

<Callout type="info">如果已经按 [Codex CLI · 安装](/codex/cli/install) 装过、并在 [CC Switch 配置](/codex/cc-switch) 中配过，桌面版启动后会自动读到同一份 `config.toml`，不需要重复配置。</Callout>

---

## 步骤

<Steps>
  <Step title="装 ChatGPT 桌面客户端">
    从 OpenAI 官方下载页获取对应平台的安装包并安装。
  </Step>
  <Step title="登录 OpenAI 账号">
    第一次启动会要求登录。临时账号也行——后面接入第三方 API 后实际请求并不会发到官方。
  </Step>
  <Step title="进入 Codex 工作区">
    打开桌面客户端 → 切到 Codex 工作区 / 模式（具体入口随版本变化）。
  </Step>
</Steps>

## 与 CLI 的差异

| 维度 | CLI | App |
| --- | --- | --- |
| 启动方式 | 终端跑 `codex` | 打开桌面客户端进入 Codex |
| 配置文件 | `~/.codex/config.toml` | 同上，**共享** |
| 推理深度 | `/effort` 或 config.toml | UI 切换 |
| 历史会话 | CLI session | App 内会话列表 |
| 适合场景 | 项目里跑命令、写脚本 | 浏览代码、对话式调试 |

<Callout type="warning">两者共享 `~/.codex/config.toml`，**改一边会影响另一边**。如果你想各走各的，需要在 App 内单独切 provider。</Callout>
