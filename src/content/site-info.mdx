## 安全下载

- 本站不托管、代理或重新打包 `.exe`、`.msi`、`.dmg`、`.AppImage`、压缩包或安装脚本。
- 软件入口优先指向产品官网、官方文档或该项目的官方 GitHub Releases；链接旁会尽量显示发布方与最终域名。
- 运行远程安装脚本前，请先打开对应官方安装文档并审阅脚本来源。不要因为教程而关闭系统安全软件、Gatekeeper、SmartScreen 或签名验证。
- 如果系统提示发布方无法验证、签名异常或下载域名与页面标注不一致，请停止安装并向产品官方支持渠道核实。

本站的链接和版本核对只能降低误下载风险，不能替代操作系统签名校验、项目官方校验值或企业安全审查。

## API Key 与账户安全

本站文档页面不提供 API Key 上传表单，也不要求用户把密钥发送给本站。示例统一使用 `sk-xxx` 等占位符；请勿把真实密钥粘贴到公开网页、聊天记录、截图、代码仓库或第三方 JSON 校验网站。

密钥应在对应官方平台或你明确选择的网关控制台创建和管理。将密钥填入第三方客户端或网关意味着请求与密钥会按该产品的实现和隐私政策处理；请在使用前核对最终 API 域名、数据流、计费主体和密钥权限。OpenAI 或 Anthropic 的官方模型列表不等于任一第三方网关实际支持的模型列表。
