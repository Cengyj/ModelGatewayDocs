# GPT Image 2

<PageHeader
  useCase="将 gpt-image-2 图片模型接入 AI 绘图工具，通过 foropencode gpt_plus 分组调用"
  audience="需要使用 OpenAI 图片生成能力的用户"
  tldr="打开 image.foropencode.com → gpt_plus 密钥 → 设置 → 供应商 codex 分组 → 填 API Key → 获取模型 → 图片工作台"
/>

<Callout type="info" title="官方模型事实与第三方网关能力分开看">
OpenAI 官方 Image generation 文档在 2026-07-26 将 `gpt-image-2` 标为最新 GPT Image 模型。本文的 `gpt_plus` 分组、`image.foropencode.com`、倍率与可用性则属于 foropencode 第三方网关/工具，不代表 OpenAI 官方提供或背书。
</Callout>

<Callout type="info" title="需要 gpt_plus 分组密钥">
  按当前 foropencode 页面说明，`gpt-image-2` 使用 `gpt_plus` 分组。请先从实际控制台确认该分组仍提供此模型，再[创建对应的第三方网关密钥](/get-key/create)。
</Callout>

## 接入步骤

<Callout type="info" title="先打开图片工具">
  `image.foropencode.com` 是第三方图片工具，不是 OpenAI 官方站点。访问 [https://image.foropencode.com](https://image.foropencode.com/) 前请核对最终域名、账户和数据处理说明；输入网关 Key 意味着该工具会使用它向所配置的 API 端点发起请求。
</Callout>

<Callout type="warning" title="第三方工具会接触密钥和输入内容">
  当前没有可引用的公开说明可确认该工具的运营主体、日志留存和密钥处理方式。不要使用同时具有其他高权限的 Key；如决定测试，应在网关侧创建用途单一、额度受限且可随时撤销的独立 Key，并避免提交敏感图片、提示词或个人信息。无法接受这一数据边界时，请等待运营方披露后再使用。
</Callout>
