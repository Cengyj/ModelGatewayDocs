> 还没装 CC Switch？先看 [CC Switch 安装](/cc-switch)。

<Callout type="warning" title="CC Switch 是第三方社区工具">
CC Switch 不是 OpenClaw、OpenAI 或 Anthropic 的官方组成部分。使用前备份 `~/.openclaw/openclaw.json`，核对其当前版本支持范围，并把 API Key、渠道 Token 和配置备份按敏感数据处理。
</Callout>

<Callout type="warning">OpenClaw 的字段名与其他工具不同——叫 **API 协议**（非「接口格式」）和 **API 端点**（非「Base URL」），注意对应填写。</Callout>

## 配置步骤

<Walkthrough title="CC Switch · 配置 OpenClaw">
  <Frame step="1" title="选中 OpenClaw 图标，点击添加"
    image="/img/cc-switch/cc-switch-openclaw-main-add.png"
    imageAlt="CC Switch 主界面：选中 OpenClaw 图标，点右上角橙色添加按钮">
    打开 CC Switch，顶部工具栏选中 **OpenClaw 图标**，点右上角橙色 **＋** 按钮新建一项。
  </Frame>

  <Frame step="2" title="填写供应商信息（按模型类型选 API 协议）"
    image="/img/cc-switch/cc-switch-openclaw-gpt-form.png"
    imageAlt="GPT 分组：API 协议选 OpenAI Responses，API 端点填 https://foropencode.com/v1">
    弹出「添加新供应商」表单，按模型类型选择 **API 协议**：

    **OpenAI 兼容分组**（上图是旧界面示例）：API 协议按 OpenClaw 当前官方支持的协议选择（manual 页记录的 custom provider schema 为 `openai-completions` / `anthropic-messages`；表单选项名以 CC Switch 当前版本为准），填入 API Key。本站截图中的第三方网关端点为：

    <CommandTable header={false} rows={[
      { cmd: 'https://foropencode.com/v1', desc: '第三方网关示例；以当前控制台或正式文档为准' },
    ]} />

    **Claude 分组**（claude-sonnet 等，下图示例）：API 协议选 `Anthropic Messages`，填入 API Key，API 端点填：

    <img src="/img/cc-switch/cc-switch-openclaw-claude-form.png" alt="Claude 分组：API 协议选 Anthropic Messages，API 端点填 https://foropencode.com（不带 /v1）" style={{width:'100%', borderRadius:'8px', margin:'8px 0'}} />

    <CommandTable header={false} rows={[
      { cmd: 'https://foropencode.com', desc: '第三方网关示例；以当前 Anthropic 兼容说明为准' },
    ]} />

    <Callout type="warning">**暂不要点「添加」**，先向下滚动完成模型配置。</Callout>
  </Frame>

  <Frame step="3" title="配置模型，填上下文窗口，点击添加"
    image="/img/cc-switch/cc-switch-openclaw-model-settings.png"
    imageAlt="模型列表：获取模型 → 添加模型 → 展开选 ID → 填上下文窗口和最大输出 → 点添加">
    在「模型列表」区域：

    1. 点击 **获取模型列表** 拉取可用模型
    2. 点击 **＋ 添加模型** 插入一行
    3. 展开模型条目，从网关实时返回的下拉列表选择 **模型 ID**；不要照抄旧截图中的名称
    4. 只有网关或模型官方资料明确时，才在「高级选项」中填写上下文窗口和最大输出 Tokens；否则保留默认并先用最小请求验证

    <Callout type="warning">截图中的模型和数值是旧界面示例，不代表 foropencode 当前支持范围。使用“获取模型列表”或网关控制台核对，不能用 OpenAI/Anthropic 官方模型表替代。</Callout>

    配置完毕后点右下角 **＋ 添加**，CC Switch 自动写入 OpenClaw 配置。添加后可用 `openclaw models list` 与 Gateway 日志核对写入的协议值是否为 OpenClaw 当前支持的协议。
  </Frame>

  <Frame step="4" title="确认配置添加成功"
    image="/img/cc-switch/cc-switch-openclaw-active-status.png"
    imageAlt="主界面配置行显示绿色「当前默认」和橙色「移除」按钮，说明配置已添加成功">
    回到主界面，配置行同时显示绿色 **「当前默认」**（正在使用）和橙色 **「移除」** 按钮即表示配置成功写入。

    OpenClaw 默认 `hybrid` reload 会热应用大多数配置，并为关键变更自动重启。查看 Gateway 日志确认是否接受配置；不要默认用强制杀进程命令。
  </Frame>
</Walkthrough>

## 可用模型

通过 CC Switch 的“获取模型列表”或 `openclaw models list --provider <provider>` 核对实际结果。OpenClaw 官方 fresh setup 的模型、模型厂商清单和 foropencode 第三方网关能力是不同范围，不能互相推定。

---

## 配置写到哪

CC Switch 将供应商信息写入 OpenClaw 配置。默认热重载会处理大多数更改：

| 平台 | 路径 |
| --- | --- |
| macOS / Linux | `~/.openclaw/openclaw.json` |
| Windows | `%USERPROFILE%\.openclaw\openclaw.json` |
