> 本教程聚焦 `openclaw` CLI、Gateway 守护进程和 Control UI。OpenClaw 官方仓库还列出 Windows Hub、macOS 菜单栏应用以及 iOS/Android nodes；可用形态会随平台与版本变化，不应理解为只有一种部署方式。

## 支持的通讯渠道

OpenClaw 的渠道与插件清单会随版本变化。Discord、Telegram、Slack、WhatsApp、飞书等仅为示例；请以 [OpenClaw 官方 Channels 文档](https://docs.openclaw.ai/channels) 当前列表为准：

<Callout type="info">
当前官方仓库列出的示例包括 WhatsApp、Telegram、Slack、Discord、Google Chat、Signal、iMessage、Microsoft Teams、Matrix、Feishu、LINE、QQ 和内置 WebChat 等。是否可用、需要哪些账户或插件，以当前 Channels 文档为准。

默认 Dashboard 地址：`http://127.0.0.1:18789/`
</Callout>

## 系统要求

<Callout type="warning" title="Node.js 版本要求">
OpenClaw 当前官方资料建议 **Node.js 24.15+**，并支持 **22.22.3+** 或 **25.9+**。运行 `node --version` 检查，版本不足时请先升级：

- [下载 Node.js LTS](https://nodejs.org/en/download)（选 Latest LTS，当前为 24.x；22.x 为仍在维护的旧 LTS 线，亦满足最低版本要求）
- 或用 `nvm use 24` 切换（需先安装 nvm）
</Callout>

## 步骤一：安装

```bash
node --version   # 推荐 v24.15+；最低按官方当前要求核对
npm install -g openclaw@latest
```

---

## 步骤二：初始化引导

```bash
openclaw onboard --install-daemon
```

## 步骤三：选择通知渠道

渠道配置所需账户、Token、回调地址和组织权限不同，不使用主观星级判断难度：

| 渠道 | 配置前先确认 |
| --- | --- |
| Telegram | 通过 [@BotFather](https://t.me/BotFather) 创建你有权管理的 bot，并按当前 Channels 文档保护 Token |
| Discord | 在 Discord Developer Portal 创建应用，按最小权限配置 bot |
| Feishu / Slack / Teams / Matrix | 查看 [OpenClaw Channels 官方文档](https://docs.openclaw.ai/channels) 的当前支持状态与平台要求 |

![渠道选择界面](/img/openclaw/image-20260302194558941.webp)
