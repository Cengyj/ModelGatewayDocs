> OpenClaw 是网关型客户端，**只有一种部署形态**（`openclaw` 守护进程 + Web UI），不分 CLI / 桌面版。

---

## 支持的通讯渠道

OpenClaw 支持 23+ 个通讯渠道，涵盖国际主流和国内常用平台：

<Callout type="info">
国际平台：Discord、Google Chat、iMessage、Matrix、Microsoft Teams、Signal、Slack、Telegram、WhatsApp、Zalo、WebChat

国内平台：飞书（Feishu / Lark）、微信（WeChat）、企业微信（WeCom）、钉钉、QQ、Line

开发者接入：WebHook、REST API、WebSocket、MQTT、自定义协议桥

默认 Dashboard 地址：`http://127.0.0.1:18789/`
</Callout>

---

## 系统要求

<Callout type="warning" title="Node.js 22.14+ 为必要条件，推荐 24+">
OpenClaw 最低要求 **Node.js 22.14+**，官方推荐 **Node.js 24+** 以获得最佳兼容性。运行 `node --version` 检查，版本不足时请先升级：

- [下载 Node.js LTS](https://nodejs.org/en/download)（选 Latest LTS 即为 22.x/24.x）
- 或用 `nvm use 24` 切换（需先安装 nvm）
</Callout>

---

## 步骤一：安装

```bash
node --version   # 确认 v22.14+（推荐 v24+）
npm install -g openclaw@latest
```

---

## 步骤二：初始化引导

