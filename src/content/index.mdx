## 30 秒上手

按你要用的工具往下找——三条路线选一条即可。

### Claude Code

以下脚本由 `claude.ai` 提供。执行前请先查看 [Anthropic 官方安装文档](https://code.claude.com/docs/en/setup)；不希望直接执行远程脚本时，按官方页面选择可审阅的安装方式。

```bash
# 1. 安装（macOS / Linux / WSL）
curl -fsSL https://claude.ai/install.sh | bash
# Windows PowerShell：irm https://claude.ai/install.ps1 | iex

# 2. 如选择第三方网关，在 CC Switch 表单中填入核对过的 Base URL 与 API Key
#    → CC Switch 会写入 ~/.claude/settings.json，无需手动编辑文件

# 3. 启动
claude
```

详细见 [Claude Code CLI 安装](/claude-code/cli/install) · [CC Switch 配置](/claude-code/cli/cc-switch)

### Codex CLI

```bash
# 1. 安装 Codex CLI
npm install -g @openai/codex

# 2. 在 CC Switch 的 Codex 向导中新建供应商，填入 API Key
#    与请求地址（详见 Codex · CC Switch 配置页）
#    模型以网关控制台或 /models 实际返回为准

# 3. 启动
codex
```

详细见 [Codex CLI 安装](/codex/cli/install)

### OpenClaw

```bash
# 1. 装 Node.js 24.15+（推荐；最低 22.22.3），然后安装 OpenClaw
npm install -g openclaw@latest

# 2. 初始化向导（一次性）
openclaw onboard --install-daemon

# 3. 浏览器打开 http://127.0.0.1:18789/ 完成配置
```

详细见 [OpenClaw 安装](/openclaw/install)
