## ⚠️ 安装 / 启动卡住先看这里

如果安装命令无法下载，或启动后报 `ConnectionRefused` / `Connection error`，**九成是网络问题**，按这个顺序自查：

1. **开了梯子的，关掉梯子**再试
2. **没开梯子的，开启梯子**再试
3. 仍不行，开启代理软件的**网卡 TUN 模式**（系统级代理），而非仅浏览器代理

> 详细排查见 [CC-009：API Error (Connection error.)](/claude-code/errors/cc-connection-error)。

## 30 秒上手

按你要用的工具往下找——三条路线选一条即可。

### Claude Code

```bash
# 1. 安装 Claude Code
curl -fsSL https://claude.ai/install.sh | bash     # macOS / Linux / WSL
irm https://claude.ai/install.ps1 | iex            # Windows PowerShell

# 2. 在 CC Switch 选择 Micu 预设供应商，填入 API Key
#    → CC Switch 会自动写入 Base URL，无需手动配置

# 3. 启动
claude
```

详细见 [Claude Code CLI 安装](/claude-code/cli/install) · [CC Switch](/cc-switch)

### Codex CLI

```bash
# 1. 装 Node.js 22+（必须），然后安装 Codex CLI
npm install -g @openai/codex

# 2. 在 CC Switch 选择 Micu 预设（框架选 Codex），填入 API Key
#    model 推荐填 gpt-5.5

# 3. 启动
codex
```

详细见 [Codex CLI 安装](/codex/cli/install)

### OpenClaw

```bash
# 1. 装 Node.js 24+（必须），然后安装 OpenClaw
npm install -g openclaw@latest

# 2. 初始化向导（一次性）
openclaw onboard --install-daemon

# 3. 浏览器打开 http://127.0.0.1:18789/ 完成配置
```

详细见 [OpenClaw 安装](/openclaw/install)

> `MICUCODELINE` 状态栏工具仅适用于 Claude Code，可额外执行 `npm install -g @zuolan/micucodeline`。详见 [推荐工具](/tools)。
