<Callout type="warning" title="安装 / 启动卡住，先看这里">
安装命令下不动，或启动后报 `ConnectionRefused` / `Connection error`，**九成是网络问题**，按顺序自查：

1. **开了梯子的，关掉梯子**再试
2. **没开梯子的，开启梯子**再试
3. 仍不行，开启代理软件的**网卡 TUN 模式**（系统级代理），而非仅浏览器代理

详细排查见 [CC-009：API Error (Connection error.)](/claude-code/errors/cc-connection-error)。

## 30 秒上手

按你要用的工具往下找——三条路线选一条即可。

### Claude Code

```bash
# 1. 安装（macOS / Linux / WSL）
curl -fsSL https://claude.ai/install.sh | bash
# Windows PowerShell：irm https://claude.ai/install.ps1 | iex

# 2. 在 CC Switch 选 foropencode 预设供应商，填入 API Key
#    → CC Switch 自动写入 Base URL，无需手动配置

# 3. 启动
claude
```

详细见 [Claude Code CLI 安装](/claude-code/cli/install) · [CC Switch 配置](/claude-code/cli/cc-switch)

### Codex CLI

```bash
# 1. 安装 Codex CLI
npm install -g @openai/codex

# 2. 在 CC Switch 选 foropencode 预设（框架选 Codex），填入 API Key
#    model 推荐 gpt-5.5

# 3. 启动
codex
```

详细见 [Codex CLI 安装](/codex/cli/install)

### OpenClaw

```bash
# 1. 装 Node.js 22.14+（推荐 24+），然后安装 OpenClaw
npm install -g openclaw@latest

# 2. 初始化向导（一次性）
openclaw onboard --install-daemon

# 3. 浏览器打开 http://127.0.0.1:18789/ 完成配置
```

详细见 [OpenClaw 安装](/openclaw/install)

[→ 令牌分组速查](/get-key/groups)
