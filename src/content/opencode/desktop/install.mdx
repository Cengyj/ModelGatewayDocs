# OpenCode 桌面版 · 安装

<VersionBadge version="v1.18.5" date="2026-07-24" license="MIT" github="https://github.com/anomalyco/opencode" />

<PageHeader

> 桌面版与 CLI **配置共享** `~/.config/opencode/opencode.json`。CLI 安装见 [OpenCode CLI · 安装](/opencode/cli/install)。

<Callout type="warning">桌面版的发布状态、平台与包管理器入口会变化。安装前先查看 [OpenCode 官方文档](https://opencode.ai/docs/) 与 [官方 Releases](https://github.com/anomalyco/opencode/releases/latest)，核对当前版本是否仍标注为 Beta。本站不托管安装包。</Callout>

---

## 安装

<Tabs defaultValue="mac">
  <Tab label="macOS" value="mac">
    ```bash
    brew install --cask opencode-desktop
    ```
  </Tab>
  <Tab label="Windows" value="win">
    ```powershell
    scoop bucket add extras
    scoop install extras/opencode-desktop
    ```
  </Tab>
</Tabs>

默认情况下，桌面版与 CLI 共享 `~/.config/opencode/opencode.json`。如果设置了 `OPENCODE_CONFIG`，实际配置文件位置可能不同，应在当前进程环境中核对。

## 与 CLI 的差异

| 维度 | CLI | 桌面版 |
| --- | --- | --- |
| 启动方式 | 终端跑 `opencode` | 启动应用 |
| 配置文件 | `~/.config/opencode/opencode.json` | 同上，**共享** |
| 当前稳定度 | 以官方 Release 为准 | 以官方 Release 为准 |
| 推荐使用场景 | 已熟悉 CLI 的开发者 | 偏好 GUI、需要图形化管理会话的用户 |

桌面版常用功能：

- **会话列表**：左侧侧栏显示历史会话，可继续上次的工作
- **模型切换**：右上角下拉切换当前 provider / 模型
- **文件浏览器**：内置的代码浏览器，定位修改位置不需要切到 IDE
- **build / plan 模式**：与 CLI 同款，按钮切换

<Callout type="info">两端共享 `opencode.json`，**改一边会影响另一边**。如果想分开用，可以借助 `OPENCODE_CONFIG` 环境变量给桌面版指定独立的配置文件路径（`OPENCODE_CONFIG_DIR` 只影响 agents / commands / plugins 等扩展目录，不用于重定位 `opencode.json`）。</Callout>
