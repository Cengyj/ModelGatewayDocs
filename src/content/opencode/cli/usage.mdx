当前官方 CLI 将非交互执行定义为 `opencode run`，脚本和 CI 应使用该子命令；旧的 `-p` / `--print` 旗标不在当前官方文档中，遇到旧教程时以 `opencode --help` 实际输出为准。

## 非交互示例

```bash
# 一次性执行
opencode run "用中文总结这个 PR 的改动"

# 指定已经配置的 provider 和模型
opencode run --model foropencode/gateway-model-id \
  "检查 src/ 下的潜在注入风险，只输出报告"
```

模型格式为 `<provider>/<model-id>`。`foropencode` 与 `gateway-model-id` 只是示例；第三方网关实际支持范围以其模型列表为准。

## TUI 命令

OpenCode 的 TUI 命令和快捷键会随版本变化。进入 TUI 后使用 `/help` 或官方 TUI 文档查看当前列表；`/init` 可用于创建项目说明，模型选择器用于切换已配置 provider。

<Callout type="warning" title="分享会话前先检查敏感信息">
如果当前版本提供会话分享功能，生成的链接可能包含提示、代码片段、文件名或工具输出。分享前删除 API Key、Token、内部 URL、客户数据和私人账号信息，并遵守仓库与组织政策。
</Callout>

## 配置与模型

默认模型写在 `opencode.json` / `opencode.jsonc` 的 `model` 字段中。临时选择可用 `--model`，但模型是否存在由当前 provider 决定；不要把 OpenAI/Anthropic 官方模型清单直接当成第三方网关清单。
