## 临时切换模型

```bash
# 启动时指定（优先级高于 opencode.json）
opencode -m fc-claude/claude-opus-4-7

# 或用环境变量（会话级别生效）
OPENCODE_MODEL="fc-claude/claude-opus-4-7" opencode
```

`model` 格式必须是 `<provider名>/<model-id>`，provider 名对应 `opencode.json` 里 `providers` 的 key。

## 非交互模式（脚本场景）

```bash
# 一次性执行，输出到终端
opencode -p "用中文总结一下这个 PR 的改动"

# 配合管道
opencode -p "生成 .gitignore for Node.js 项目" > .gitignore

# 临时换模型 + 非交互
OPENCODE_MODEL="fc-claude/claude-haiku-4-5" opencode -p "列出 src/ 下所有函数名"
```

## AGENTS.md（上下文文件）

OpenCode 读取项目根目录的 `AGENTS.md` 作为持久上下文，类似 Claude Code 的 `CLAUDE.md`：

```bash
# 在 TUI 里输入，自动生成 AGENTS.md
/init
```

生成后建议 git commit，团队共用一份上下文。子目录的 `AGENTS.md` 支持嵌套覆盖。
