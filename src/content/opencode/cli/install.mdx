> CLI 与桌面版**配置共享** `~/.config/opencode/opencode.json`，但**安装入口不同**。桌面版安装见 [OpenCode 桌面版 · 安装](/opencode/desktop/install)。

## 支持哪些供应商？

OpenCode 内置 75+ 供应商适配，覆盖主流国际服务和国产中转：

| 类别 | 示例 |
| --- | --- |
| 官方大厂 | Anthropic (Claude)、OpenAI、Google Gemini、AWS Bedrock、Azure OpenAI |
| 高性价比 | DeepSeek、Groq、Mistral、Together AI |
| 国内中转 | OpenRouter、自建 API Gateway、各类兼容 OpenAI 格式的接口 |
| 本地部署 | Ollama（完全离线，免 API key） |

配置供应商时，只需在 `opencode.json` 的 `provider` 字段指定端点和 key；CC Switch 会自动生成此配置，无需手填。

## 系统要求

<Callout type="info" title="环境要求">
- **Node.js** 20+（npm 安装时需要）
- **操作系统**：macOS、Linux（含 WSL2）、Windows（Scoop / Chocolatey）、Arch Linux
- **磁盘**：约 100 MB
</Callout>

## 安装

<Tabs defaultValue="curl">
  <Tab label="curl 一键脚本" value="curl">
    官方推荐，自动检测平台、安装最新版本：

    ```bash
    curl -fsSL https://opencode.ai/install | bash
    ```

    安装结束后重新加载 shell：

    ```bash
    source ~/.bashrc   # bash 用户
    source ~/.zshrc    # zsh 用户
    ```
  </Tab>
  <Tab label="npm" value="npm">
    ```bash
    npm i -g opencode-ai@latest
    ```

    注意包名是 `opencode-ai`，不是 `opencode`。
  </Tab>
  <Tab label="Homebrew (macOS)" value="brew">
    官方 tap（优先，始终最新）：

    ```bash
    brew install anomalyco/tap/opencode
    ```

    或直接：

    ```bash
    brew install opencode
    ```
  </Tab>
  <Tab label="Windows" value="win">
    Scoop：

    ```powershell
    scoop install opencode
    ```

    Chocolatey：

    ```powershell
    choco install opencode
    ```
  </Tab>
  <Tab label="Arch Linux" value="arch">
    官方仓库：

    ```bash
    sudo pacman -S opencode
    ```

    AUR（社区构建二进制）：

    ```bash
    paru -S opencode-bin
    ```
  </Tab>
</Tabs>

## 常见问题

<Callout type="warning" title="旧版本升级注意">
如果你安装的是早于 0.1.x 的旧版本，官方要求**先完全卸载再重装**，不能直接覆盖升级：

```bash
# 卸载旧版（npm 安装的情况）
npm uninstall -g opencode-ai
# 再按上面的 curl 脚本重装
```
</Callout>
