> CLI 与桌面版**配置共享** `~/.config/opencode/opencode.json`，但**安装入口不同**。桌面版安装见 [OpenCode 桌面版 · 安装](/opencode/desktop/install)。

## 支持哪些供应商？

OpenCode 可通过内置适配和自定义 provider 连接多种服务；具体列表会随版本变化，应以 [OpenCode 官方 Providers 文档](https://opencode.ai/docs/providers/) 为准：

| 类别 | 示例 |
| --- | --- |
| 模型厂商与云平台 | Anthropic、OpenAI、Google Vertex AI、Amazon Bedrock、Azure OpenAI 等；以官方 Providers 列表为准 |
| 其他服务商 | DeepSeek、Groq、Together AI、OpenRouter、Ollama 等 |
| 自定义兼容端点 | 自建 API Gateway 或经双方文档确认的兼容接口 |
| 本地模型运行时 | Ollama 等；是否离线取决于模型、工具和其他已启用功能 |

可按 OpenCode 官方文档在 `opencode.json` 的 `provider` 字段配置端点和 Key；也可选择第三方 CC Switch 生成配置，但应先查看它准备写入的内容并备份原文件。

## 系统要求

<Callout type="info" title="环境要求">
- **Node.js / 包管理器**：仅在选择 npm 等对应安装方式时需要
- **操作系统**：按官方安装页选择 macOS、Linux、Windows 或 Arch Linux 的当前安装方式
- **下载来源**：`opencode.ai`、`github.com/anomalyco/opencode` 或官方文档列出的包管理器
</Callout>

## 安装

<Tabs defaultValue="curl">
  <Tab label="官方安装脚本" value="curl">
    OpenCode 官方文档列出的安装脚本会检测平台并安装当前版本：

    <Callout type="warning">该命令会从 `opencode.ai` 下载并执行脚本。请先查看 [OpenCode 官方安装文档](https://opencode.ai/docs/) 或下载脚本到本地审阅；域名、证书或内容不一致时停止执行。</Callout>

    ```bash
    curl -fsSL https://opencode.ai/install | bash
    ```

    安装结束后按脚本输出更新 PATH，或打开一个新终端；不要盲目 `source` 不属于当前 shell 的配置文件。
  </Tab>
  <Tab label="npm" value="npm">
    ```bash
    npm i -g opencode-ai@latest
    ```

    注意包名是 `opencode-ai`，不是 `opencode`。
  </Tab>
  <Tab label="Homebrew (macOS)" value="brew">
    官方仓库当前优先推荐的 tap：

    ```bash
    brew install anomalyco/tap/opencode
    ```

    或直接：

    ```bash
    brew install opencode
    ```
  </Tab>
  <Tab label="Windows" value="win">
    Scoop：

    ```powershell
    scoop install opencode
    ```

    Chocolatey：

    ```powershell
    choco install opencode
    ```
  </Tab>
  <Tab label="Arch Linux" value="arch">
    官方仓库：

    ```bash
    sudo pacman -S opencode
    ```

    AUR（社区构建二进制）：

    ```bash
    paru -S opencode-bin
    ```
  </Tab>
</Tabs>
