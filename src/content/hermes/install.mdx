## 核心特性

Hermes Agent 的核心区别在于**持久学习**机制，而不是单次会话：

| 特性 | 说明 |
| --- | --- |
| 跨会话记忆（GEPA） | 每次对话后自动提炼并写入长期记忆，下次打开直接延续上下文 |
| Cron 定时任务 | 可配置后台定时执行代理任务（日报生成、数据同步等） |
| 持久 Shell | 同一 shell 进程在多次对话间保持活跃，不丢失工作目录和环境变量 |
| 多平台 | 同一配置文件（`~/.hermes/config.yaml`）跨 macOS / Linux / Windows / Termux 同步 |

---

## 系统要求

<Callout type="info" title="环境要求">
- **Python** 3.10+（`uv` 会自动处理，源码安装需要手动装）
- **操作系统**：Linux、macOS、Windows（PowerShell）、Android Termux
- **Termux 特别注意**：请用 `[termux]` extra，不要装完整 extra（有 Android 不兼容的语音依赖）
</Callout>

## 安装

<Tabs defaultValue="unix">
  <Tab label="Linux / macOS / WSL2" value="unix">
    ```bash
    curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
    ```

    安装结束后重新加载 shell：

    ```bash
    source ~/.bashrc   # bash 用户
    source ~/.zshrc    # zsh 用户
    hermes
    ```
  </Tab>
  <Tab label="Windows PowerShell" value="ps">
    ```powershell
    iex (irm https://hermes-agent.nousresearch.com/install.ps1)
    ```
  </Tab>
  <Tab label="Termux (Android)" value="termux">
    ```bash
    curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
    ```

    <Callout type="warning">Termux 下脚本会自动使用 `[termux]` extra，跳过语音依赖。若手动 pip 安装，请用 `pip install hermes-agent[termux]` 而非 `[all]`。</Callout>
  </Tab>
  <Tab label="开发者源码" value="src">
    需要先安装 [uv](https://github.com/astral-sh/uv)：

    ```bash
    pip install uv
    uv pip install -e ".[all,dev]"
    ```
  </Tab>
</Tabs>

## 快速配置向导

第一次启动时官方推荐：

```bash
hermes setup --portal
```

向导会引导你配置 API Provider（支持 Anthropic、OpenAI、OpenRouter 等）、记忆存储路径、Shell 集成。
