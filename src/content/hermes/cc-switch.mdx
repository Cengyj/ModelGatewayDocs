## 配置步骤

<Walkthrough title="CC Switch · 配置 Hermes Agent">
  <Frame step="1" title="选中 Hermes 图标，点击添加"

    image="/img/cc-switch/cc-switch-openclaw-gpt-form.png"

    弹出「添加新供应商」表单，按模型类型选择 **API 协议**：

    **GPT 分组**（gpt-5.5 / gpt-5.4 等，上图示例）：API 协议选 `OpenAI Responses`，填入 API Key，API 端点填：

    <CommandTable header={false} rows={[
      { cmd: 'https://foropencode.com/v1', desc: 'GPT 系列必须带 /v1' },
    ]} />

    **Claude 分组**（claude-sonnet 等，下图示例）：API 协议选 `Anthropic Messages`，填入 API Key，API 端点填：

    <img src="/img/cc-switch/cc-switch-openclaw-claude-form.png" alt="Claude 分组：API 协议选 Anthropic Messages，API 端点填 https://foropencode.com（不带 /v1）" style={{width:'100%', borderRadius:'8px', margin:'8px 0'}} />

    <CommandTable header={false} rows={[
      { cmd: 'https://foropencode.com', desc: 'Claude 系列不带 /v1' },
    ]} />

    <Callout type="warning">**暂不要点「添加」**，先向下滚动完成模型配置。</Callout>
  </Frame>

  <Frame step="3" title="配置模型，填上下文长度，点击添加"
    image="/img/cc-switch/cc-switch-hermes-form.png"
    imageAlt="表单下半部分：确认 API 端点带 /v1，填 API Key，获取模型列表，添加模型，选 ID，填上下文长度">
    向下滚动，在「模型列表」和「供应商高级选项」区域：

    1. **确认 API 端点**已填写（GPT 分组需带 `/v1`）
    2. 填入 **API Key**
    3. 点击 **获取模型列表** 拉取可用模型
    4. 点击 **＋ 添加模型** 插入一行
    5. 展开模型条目，从下拉列表选择 **模型 ID**（如 `gpt-5.4`、`gpt-5.5`）
    6. 填写 **上下文长度**：

    | 模型 | 上下文长度 | 最大输出 |
    | --- | --- | --- |
    | `gpt-5.5` | `270000` | `128000` |
    | `gpt-5.4` | `1050000` | `128000` |
    | `gpt-5.4-mini` | `400000` | `128000` |

    <Callout type="warning">**gpt-5.5 实际有效上下文约 270K**——填 1M 会触发 `context_length_exceeded`，建议上下文长度填 `270000`。</Callout>

    7. 在「供应商高级选项」中将 **请求间隔（秒）** 设为 `0.5`，以避免触发速率限制
    8. 点右下角 **＋ 添加**，CC Switch 自动写入 Hermes 配置
  </Frame>

  <Frame step="4" title="确认配置添加成功"
    image="/img/cc-switch/cc-switch-hermes-active-status.png"
    imageAlt="主界面配置行显示橙色「移除」按钮，鼠标悬停显示绿色「使用中」，说明配置已生效">
    回到主界面，配置行显示橙色 **「移除」** 按钮即表示配置成功写入；鼠标悬停后显示绿色 **「使用中」** 表示配置已生效。

    **重启终端**，下次跑 `hermes` 即读取新配置。
  </Frame>
</Walkthrough>

## 可用模型

### OpenAI 模型

API 协议选 `OpenAI Responses`，API 端点填 `https://foropencode.com/v1`：

| 模型 ID | 上下文窗口 | 最大输出 |
| --- | --- | --- |
| `gpt-5.5` | 270,000（普通）/ 1,050,000（Pro/Plus Codex） | 128,000 |
| `gpt-5.4` | 1,050,000 | 128,000 |
| `gpt-5.4-mini` | 400,000 | 128,000 |

### Anthropic 模型

API 协议选 `Anthropic Messages`，API 端点填 `https://foropencode.com`（**不带 `/v1`**）：

| 模型 ID | 上下文窗口 | 最大输出 |
| --- | --- | --- |
| `claude-opus-4-8` | 1,000,000 | 128,000 |
| `claude-sonnet-4-6` | 1,000,000 | 64,000 |
| `claude-haiku-4-5-20251001` | 200,000 | 64,000 |

## 三类 API 模式

Hermes 支持三种 API 协议，对应不同的模型分组：

| API 协议 | 适用场景 | API 端点 |
| --- | --- | --- |
| `OpenAI Responses` | GPT 模型（gpt-5.5、gpt-5.4 等） | `https://foropencode.com/v1` |
| `Anthropic Messages` | Claude 模型（claude-sonnet 等） | `https://foropencode.com` |
| `OpenAI Chat Completions` | 其他 OpenAI 兼容端点 | `https://foropencode.com/v1` |

多个分组可以各建一份配置，在 CC Switch 里互相切换。

## 主要功能

- **自学习循环**：从历史会话里抽取可复用的「技能」
- **消息网关**：可以从 Telegram / Discord / Slack / WhatsApp / Signal / 邮件 / CLI 触发
- **会话搜索 + 摘要**：基于 FTS5 全文索引，配合 LLM 摘要
- **多终端后端**：本地、Docker、SSH、Singularity、Modal、Daytona 六种
- **附加能力**：定时任务（cron）、子代理派遣、语音备忘录转写、MCP 集成、从 OpenClaw 迁移工具
