## 可用模型

模型以 `hermes model` 和第三方网关实际列表为准。CC Switch 的表单选项、Nous Research 官方 provider 清单和 OpenAI/Anthropic 官方模型清单不能证明 foropencode 已提供同名模型。

---

## 三类 API 模式

Hermes 对不同 provider 支持多种协议，`api_mode` 并非所有 provider 的通用必填字段。若 CC Switch 当前仍提供以下选项，应与 Hermes 和网关双方文档交叉核对：

| API 协议 | 适用场景 | API 端点 |
| --- | --- | --- |
| `OpenAI Responses` | 网关实际提供且 Hermes 支持的 Responses 兼容模型 | `https://foropencode.com/v1`（示例） |
| `Anthropic Messages` | 网关实际提供且 Hermes 支持的 Anthropic 兼容模型 | `https://foropencode.com`（示例） |
| `OpenAI Chat Completions` | 其他经双方文档确认的 OpenAI 兼容端点 | `https://foropencode.com/v1`（示例） |

多个分组可以各建一份配置，在 CC Switch 里互相切换。

## 主要功能

- **自学习循环**：从历史会话里抽取可复用的「技能」
- **消息网关**：可以从 Telegram / Discord / Slack / WhatsApp / Signal / 邮件 / CLI 触发
- **会话搜索 + 摘要**：基于 FTS5 全文索引，配合 LLM 摘要
- **多终端后端**：本地、Docker、SSH、Singularity、Modal、Daytona 六种
- **附加能力**：定时任务（cron）、子代理派遣、语音备忘录转写、MCP 集成、从 OpenClaw 迁移工具
