# 获取 API 密钥

<PageHeader
  useCase="在 foropencode 控制台新建 API 密钥，供 Claude Code、Codex、OpenCode 等客户端使用"
  audience="首次使用 foropencode 的新用户"
  tldr="控制台 → API 密钥 → 创建 → 填名称 → 选分组 → 保存更改"
/>

<Callout type="warning" title="这是第三方网关密钥，不是厂商官方 Key">
本页介绍 `foropencode.com` 模型网关（本站的配套网关，相对 OpenAI/Anthropic 属第三方服务）的控制台，不是 OpenAI 或 Anthropic 官方密钥平台。文档页面本身不提供密钥上传表单；请只在你确认的控制台或客户端中输入 Key，并在创建前核对计费主体、数据处理和最终 API 域名。官方厂商 Key 应在对应厂商官方平台创建和管理。本站与该网关的关系见[站点说明](/site-info#contact)。
</Callout>

  <Frame
    title="① 点击控制台"
    caption="在 foropencode.com 顶部导航栏点击「控制台」。"
  />
  <Frame
    title="② 进入 API 密钥"
    caption="控制台左侧菜单 → 常规 → 点击「API 密钥」。"
  />
  <Frame
    title="③ 点击创建 API 密钥"
    caption="列表页右上角点击「+ 创建 API 密钥」按钮，弹出创建表单。"
  />
  <Frame
    title="④ 输入密钥名称"
    caption="在「名称」输入框填写一个便于识别的名字，例如 `claude-code-work`。"
  />
  <Frame
    title="⑤ 选择对应分组"
    caption="在「分组」下拉框选择该密钥要绑定的令牌分组。按项目内现有控制台截图，分组可能影响可用模型与倍率；当前规则须以登录后的控制台为准。"
  >
    <Callout type="info" title="分组决定可用模型">
      当前截图显示密钥需要选择分组，但没有公开网关文档可证明其权限规则。创建后请用控制台或客户端返回的模型列表核对实际范围；如需区分用途，可分别创建用途单一、可独立撤销的密钥。详见[令牌分组](/get-key/groups)。
    </Callout>
  </Frame>
  <Frame
    title="⑥ 点击保存更改"
    caption="确认信息无误后点击右下角「保存更改」，密钥即创建成功并出现在列表中。"
  />
</Walkthrough>

## 复制密钥

<Callout type="warning" title="密钥只显示一次">
  按当前控制台界面，创建后应立即在安全位置保存密钥；示例格式仅写作 `sk-xxx`。不要把真实 Key 粘贴到本站文档、在线 JSON 校验站、公开 Issue、截图或聊天记录。控制台的显示与找回规则可能变化，以实际界面为准。
</Callout>

## 资料来源与限制
