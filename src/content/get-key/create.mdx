## 创建步骤

<Frame
  title="API 密钥创建流程"
  image="/img/foropencode/create-key-overview.png"
  imageAlt="API 密钥创建教程：① 点击控制台 ② 进入 API 密钥 ③ 点击创建 API 密钥 ④ 输入密钥名称 ⑤ 选择对应分组 ⑥ 点击保存更改"
  caption="完整流程：控制台 → API 密钥 → 创建 → 填名称 → 选分组 → 保存更改"
/>

<Walkthrough>
  <Frame
    title="① 点击控制台"
    caption="在 foropencode.com 顶部导航栏点击「控制台」。"
  />
  <Frame
    title="② 进入 API 密钥"
    caption="控制台左侧菜单 → 常规 → 点击「API 密钥」。"
  />
  <Frame
    title="③ 点击创建 API 密钥"
    caption="列表页右上角点击「+ 创建 API 密钥」按钮，弹出创建表单。"
  />
  <Frame
    title="④ 输入密钥名称"
    caption="在「名称」输入框填写一个便于识别的名字，例如 `claude-code-work`。"
  />
  <Frame
    title="⑤ 选择对应分组"
    caption="在「分组」下拉框选择该密钥要绑定的令牌分组。不同分组对应不同的模型访问权限和倍率。"
  >
    <Callout type="info" title="分组决定可用模型">
      选择分组后，该密钥只能调用该分组内的模型。若需要同时使用 Claude 和 GPT，建议分别创建两个密钥并绑定不同分组。详见[令牌分组](/get-key/groups)。
    </Callout>
  </Frame>
  <Frame
    title="⑥ 点击保存更改"
    caption="确认信息无误后点击右下角「保存更改」，密钥即创建成功并出现在列表中。"
  />
</Walkthrough>

---

## 复制密钥

<Callout type="warning" title="密钥只显示一次">
  创建成功后请立即复制完整密钥字符串（格式为 `sk-...`）。列表页后续只显示密钥的前几位，无法再查看完整内容。若遗失，需要重新创建。
</Callout>
