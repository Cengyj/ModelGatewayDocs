## 切换步骤

<Frame
  title="API 密钥分组切换流程"
  image="/img/foropencode/switch-group-overview.png"
  imageAlt="API 密钥分组切换教程：步骤1 进入 API 密钥列表 → 点击操作菜单 → 编辑；步骤2 选择目标分组并保存更改"
  caption="完整流程：控制台 → API 密钥 → 操作菜单（···）→ 编辑 → 选分组 → 保存更改"
/>

<Walkthrough>
  <Frame
    title="① 点击控制台 / 进入 API 密钥"
    caption="在 foropencode.com 顶部导航栏点击「控制台」，然后在左侧菜单进入「API 密钥」列表。"
  />
  <Frame
    title="② 点击操作菜单 → 编辑"
    caption="找到要切换分组的密钥，点击该行末尾的「···」操作菜单，选择「编辑」。"
  >
    <Callout type="info">
      操作菜单还提供「复制密钥」「复制连接信息」「CC 切换」「聊天」「删除」等快捷操作。
    </Callout>
  </Frame>
  <Frame
    title="③ 分组选 gpt_plus（或目标分组）"
    caption="在「更新 API 密钥」弹窗中点击「分组」下拉框，从列表中选择目标分组。每个分组旁显示倍率。"
  />
  <Frame
    title="④ 点击保存更改"
  caption="确认分组选择无误后点击右下角「保存更改」。返回列表核对分组名称，并以控制台的保存反馈为准。"
  />
</Walkthrough>

---

<Callout type="warning" title="切换后先验证">
  当前页面无法独立验证第三方网关的生效时机。保存后先在控制台确认目标分组、模型权限和计费规则，再用低风险测试请求验证；示例密钥始终使用 `sk-xxx`，不要把真实密钥粘贴到文档页面或公开截图。
</Callout>
