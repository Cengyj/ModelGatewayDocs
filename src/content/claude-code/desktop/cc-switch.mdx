## 配置步骤

<Walkthrough title="CC Switch · 配置 Claude Desktop">
  <Frame step="1" title="选中 Claude Desktop 图标，点击添加"
    image="/img/cc-switch/cc-switch-desktop-main-add.png"
    imageAlt="CC Switch 主界面：选中 Claude Desktop 图标，点右上角添加按钮">
    打开 CC Switch，顶部工具栏按名称选中 **Claude Desktop 图标**。点右上角 **＋** 按钮新建一项；不要依赖图标排列位置。
  </Frame>

  <Frame step="2" title="填写供应商信息"
    image="/img/cc-switch/cc-switch-add-provider-form.png"
    imageAlt="添加新供应商表单：名称、API Key、请求地址">
    弹出「添加新供应商」表单，按顺序填写：

    - **供应商名称**：随便取，如 `for`
    - **API Key**：你在 [foropencode.com](https://foropencode.com) 创建的 `sk-xxx`
    - **请求地址**：点击右侧图标复制后粘贴

    <CommandTable header={false} rows={[
      { cmd: 'https://foropencode.com', desc: '必须 HTTPS、不带 /v1 结尾' },
    ]} />

    填好后点右下角 **添加**。
  </Frame>

  <Frame step="3" title="确认「使用中」，重启桌面版"
    image="/img/cc-switch/cc-switch-active-status.png"
    imageAlt="鼠标悬停在配置行上，显示「使用中」表示配置成功">
    鼠标悬停在刚添加的配置行上，显示 **「使用中」** 只表示 CC Switch 已写入配置，不代表 Claude 当前版本接受该配置。完全重启后仍应在 Claude 的可见界面核对实际 provider 和最终请求域名。
  </Frame>
</Walkthrough>

## 可用模型

Anthropic 官方当前模型清单与第三方网关实际支持范围是两套事实。选择模型时，以网关控制台或模型列表的实时结果为准，并确认 Claude 当前版本支持对应协议；不要根据本站静态表格推定可用性。

---

## 配置写到哪

CC Switch 与 Claude Desktop 的配置路径可能随两边版本变化。本次无法从 Anthropic 官方资料确认一个稳定、受支持的桌面版内部路径，因此不再宣称它与 CLI 共用 `~/.claude/settings.json`。以 CC Switch 当前版本的备份提示和 Claude 官方说明为准。
