## 支持平台

Claude 桌面版的可下载平台与最低系统版本可能随发布变化。请以 [Claude 官方下载页（claude.com）](https://claude.com/download) 当前显示的 macOS 和 Windows 要求为准。Linux 版处于 beta，官方支持 Ubuntu 和 Debian（x64、arm64），入口见官方下载页；Linux 用户也可选择 [Claude Code CLI](/claude-code/cli/install)。

## 登录与第三方网关

官方账户登录、API Key 登录和第三方推理入口不是同一件事。当前应用要求哪种登录方式，以 Claude 应用内提示和官方支持文档为准。

按 [官方 LLM Gateway 文档](https://code.claude.com/docs/en/llm-gateway-connect) 配置第三方推理（Third-Party Inference）时：

1. 没有管理员分发配置的设备，可在应用内打开 **Help → Troubleshooting → Enable Developer Mode**，重启后从 **Developer → Configure Third-Party Inference** 填写网关 Base URL
2. 先核对第三方网关的最终域名、数据处理、计费主体和支持模型
3. API Key 只填入你明确选择的客户端或网关表单，不要粘贴到文档页面、在线 JSON 校验站或公开截图
4. 注意官方限制：网关配置激活后，桌面版仅在本机运行会话，SSH / 云环境与 Remote Control 不可用；管理员分发的配置优先并使表单只读
5. 如果当前版本界面没有该入口，停止配置，不要手写内部状态来绕过首次引导

CC Switch 是第三方社区工具，不是 Anthropic 产品。使用前请查看 [CC Switch 官方仓库](https://github.com/farion1231/cc-switch) 当前支持列表并备份现有配置。

## 验证

- 应用来自 `claude.com` 官方下载入口
- 操作系统没有报告签名或发布方异常
- 登录或第三方推理入口来自当前应用的可见界面，而不是通过未记录的内部文件强制启用
- 选择第三方网关时，已明确请求最终发送到哪个域名
