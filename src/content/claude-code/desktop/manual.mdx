<Callout type="warning" title="不要手写内部配置文件">
旧版页面建议手动创建 `Claude-3p/claude_desktop_config.json` 并写入 `thirdPartyApiInfo`。官方 [LLM Gateway 文档](https://code.claude.com/docs/en/llm-gateway-connect) 现已提供受支持的配置入口（管理员分发配置，或应用内 Developer Mode 表单），因此不应再手写未记录的内部文件或用它强制显示 Gateway 按钮。
</Callout>

---

## 推荐核对顺序

1. 从 [Claude 官方下载页](https://claude.com/download) 安装当前版本
2. 若组织已分发第三方推理配置，桌面版无需额外设置即路由到网关
3. 个人设备按官方文档启用：**Help → Troubleshooting → Enable Developer Mode**（重启后出现 Developer 菜单）→ **Developer → Configure Third-Party Inference**，填写网关 Base URL
4. 确认请求最终域名、网关运营方、数据处理与计费方式
5. 界面没有该入口或表单只读时停止操作，不创建内部目录、不修改 onboarding 状态，也不从同名 GitHub 项目推断配置 schema

## JSON 仅做本地校验

如果产品官方支持要求你编辑 JSON，请在本机验证语法，避免把可能含密钥的文件粘贴到在线 JSON 校验网站：

<Tabs defaultValue="mac">
  <Tab label="macOS / Linux" value="mac">
    ```bash
    python3 -m json.tool /path/to/config.json >/dev/null
    ```
  </Tab>
  <Tab label="Windows PowerShell" value="win">
    ```powershell
    Get-Content "C:\path\to\config.json" -Raw | ConvertFrom-Json | Out-Null
    ```
  </Tab>
</Tabs>

这些命令只检查 JSON 语法，不会证明字段受 Claude 当前版本支持。

## API Key 安全

- 示例只使用 `sk-xxx`；不要在截图、Issue、聊天或文档页面公开真实 Key
- 官方 Anthropic Key 应在 Anthropic 官方平台创建和管理；第三方网关 Key 应在该网关自己的控制台管理
- 第三方网关不是 Anthropic，网关支持的模型和上下文以其实际模型列表为准
- 若工具要求关闭系统安全软件、绕过签名或修改内部状态才能启用，停止使用并向官方支持核实
