## 继续上次对话

```bash
# 接着上次中断的对话继续工作
claude --continue

# 查看所有后台会话，找到 session-id
claude agents

# 继续指定会话
claude --resume abc123
```

<Callout type="tip">`--continue` 是最常用的"回来继续干活"方式。Claude Code 会加载最近一次会话的上下文，你可以直接接着提问，不用重新交代背景。</Callout>

## 自动授权 / 跳过确认

Claude Code 默认对每个工具调用（写文件、执行命令等）都会询问你是否允许。以下两个方式可以跳过：

### `--dangerously-skip-permissions`

```bash
claude --dangerously-skip-permissions
```

启动后 Claude Code 对**所有**工具调用直接执行，不再弹确认。适合：

- CI/CD 自动化流水线
- 已充分审查任务、不想被打断的连续工作流
- 脚本调用 `--print` 模式时不需要交互

<Callout type="warning">**只在你信任任务内容时使用。** `--dangerously-skip-permissions` 不区分危险程度，`rm -rf` 和 `echo hello` 都会直接执行。建议结合 `settings.json` 的 `permissions.deny` 规则做底线保护。</Callout>

### 细粒度权限规则（推荐替代方案）

如果只想跳过特定工具的确认，在 `~/.claude/settings.json` 里用 `permissions.allow` 白名单更安全：

```json
{
  "permissions": {
    "allow": ["Bash(git:*)", "Bash(npm:*)", "Read(*)", "Write(src/**)"],
    "deny": ["Bash(rm:*)", "Bash(git push --force:*)"]
  }
}
```

## 非交互模式（脚本场景）

```bash
# 一次性执行，结果输出到终端
claude --print "用中文总结一下这个 PR 的改动" 

# 输出 JSON（包含 token 用量）
claude --print --output-format json "列出 src/ 下所有函数名" 

# 配合 CI，跳过确认 + 非交互
claude --print --dangerously-skip-permissions \
  "检查 src/api.ts 里有没有 SQL 注入漏洞，输出 JSON 报告"

# 把结果传给其他命令
claude --print "生成 .gitignore for Node.js 项目" > .gitignore
```

## 子代理 / 后台任务（v2.x）

```bash
# 查看所有正在运行的后台会话
claude agents

# 检查鉴权状态
claude auth status
claude auth status --text   # 人可读格式

# 生成 CI/CD 用的长效 Token（不需要浏览器）
claude setup-token
```

## 版本与更新

```bash
# 查看版本
claude --version

# 更新到最新版（原生安装方式）
claude update

# 检查更新但不安装
claude --version --no-update-check
```
