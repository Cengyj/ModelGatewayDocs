# Claude Code CLI · 安装

<Callout type="info" title="官方登录与第三方网关是不同路径">
Claude Code 支持 Anthropic 官方账户/API 与受支持的 LLM Gateway 配置。使用第三方网关时，请按网关要求选择 `ANTHROPIC_API_KEY` 或 `ANTHROPIC_AUTH_TOKEN`，并确认数据、计费和模型可用性由该网关处理；不要通过修改内部状态字段跳过登录或首次引导。
</Callout>

> 下一步配 API：可选择第三方图形界面 [CC Switch 配置](/claude-code/cli/cc-switch)，或按 [手动配置](/claude-code/cli/manual) 审阅并编辑文件。

## 系统要求

<Callout type="info" title="环境要求">
- **Node.js**：原生安装不要求预装；npm 安装方式自 v2.1.198 起需要 Node.js 22+
- **操作系统**：macOS 13+、Ubuntu 20.04+ / Debian 10+、Windows 10 1809+（含 WSL2）
- **Windows 原生**：建议安装 Git for Windows 以启用 Bash 工具；未安装时 Claude Code 会改用 PowerShell 工具执行命令
- **硬件**：4 GB+ 内存，x64 或 ARM64
</Callout>

---

## 准备 Git（Windows 原生建议安装）

Windows 原生环境下，Git for Windows 是可选项：安装后 Claude Code 使用 Git Bash 提供 Bash 工具；未安装时会改用 PowerShell 工具执行命令。WSL / macOS / Linux 系统自带或自己装好即可。

下载：[Git for Windows 官方安装页（git-scm.com）](https://git-scm.com/install/windows)。打开安装器后核对应用名称和发布来源，再按你的终端、PATH 与组织策略选择安装选项；不需要为教程关闭 SmartScreen 或签名检查。

```powershell
git --version
```

## 安装

Anthropic 当前推荐原生安装；npm 是官方文档中的高级安装选项，安装的是同一个原生二进制。先查看 [Anthropic 官方安装文档（code.claude.com）](https://code.claude.com/docs/en/setup)，再选择与平台匹配的方式。

<Callout type="warning" title="远程安装脚本安全说明">
下面的脚本来自 Anthropic 官方域名 `claude.ai`，会下载并安装 Claude Code。执行前可先在浏览器打开脚本地址或下载到本地审阅；如果最终域名、证书或脚本内容与官方文档不一致，请停止执行。无需也不应关闭系统安全机制。
</Callout>

<Tabs defaultValue="mac">
  <Tab label="macOS / Linux / WSL" value="mac">
    ```bash
    curl -fsSL https://claude.ai/install.sh | bash
    ```

    安装完重新加载 shell 或新开终端：

    ```bash
    source ~/.bashrc   # bash 用户
    source ~/.zshrc    # zsh 用户
    ```
  </Tab>
  <Tab label="Windows PowerShell" value="ps">
    ```powershell
    irm https://claude.ai/install.ps1 | iex
    ```
  </Tab>
  <Tab label="Windows CMD" value="cmd">
    ```cmd
    curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
    ```
  </Tab>
  <Tab label="Homebrew (macOS)" value="brew">
    ```bash
    brew install --cask claude-code
    ```
  </Tab>
  <Tab label="WinGet (Windows)" value="winget">
    ```powershell
    winget install Anthropic.ClaudeCode
    ```
  </Tab>
</Tabs>

## 常见问题

<Callout type="info" title="之前用 npm 安装的怎么办？">
`npm install -g @anthropic-ai/claude-code` 仍是官方文档记录的高级安装选项，安装同一个原生二进制（v2.1.198 起需 Node.js 22+），且在 npm 全局目录可写时同样支持自动更新。如果想迁移到原生安装：

1. 先卸载：`npm uninstall -g @anthropic-ai/claude-code`
2. 再用上面的原生脚本重装
</Callout>

<Callout type="warning" title="安装命令无法访问？">
先确认 `claude.ai` 与 `code.claude.com` 的证书和最终域名正常，再检查 DNS、系统时间、企业防火墙与已获授权的代理设置。不要通过关闭安全软件或跳过 TLS 校验完成安装。仍失败时请查看 [Anthropic 官方安装排障](https://code.claude.com/docs/en/setup)。
</Callout>
