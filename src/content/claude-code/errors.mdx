## 🌐 网络 / 连接类

请求未到达服务器、超时、被拦截。**先确认网络与代理，再排查配置**。

| 编号 | 现象 | 根因 | 状态 |
| --- | --- | --- | --- |
| [CC-005](/claude-code/errors/cc-onboarding-connection-block) | 首次启动即报 Unable to connect to Anthropic services | `hasCompletedOnboarding` 字段缺失，Onboarding 探测绕过中转直连官方端点失败 | ✅ 已解决 |
| [CC-009](/claude-code/errors/cc-connection-error) | API Error (Connection error.) | 本地到服务器链路不通，代理节点失效或网络路由异常 | 常见 |
| [CC-010](/claude-code/errors/cc-request-timed-out) | API Error (Request timed out.) | 网络延迟过高（情况 A）或上下文 token 过多处理超时（情况 B） | 常见 |
| [CC-017](/claude-code/errors/cc-webfetch-preflight-fail) | WebFetch 报错，目标网站可访问但联网失效 | CC 抓取前向 claude.ai 发预检请求，国内网络拦截 claude.ai 导致预检失败 | ✅ 已解决 |
| CC-008 | 403 / Missing API Key | 配置冲突或 settings.json 被意外修改，推荐用 CC Switch 重新写入 | 常见 |
| CC-012 | Overloaded / 500 | 官方服务过载或故障，查 [status.anthropic.com](https://status.anthropic.com) 确认状态 | 常见 |

## 🔑 认证 / Key 类

返回 401 / Invalid API Key / 鉴权失败。**优先排查配置覆盖关系**：环境变量 > settings.json > CC Switch。

| 编号 | 现象 | 根因 | 状态 |
| --- | --- | --- | --- |
| CC-002 | 401 / Invalid API Key | 中转 API 的 `ANTHROPIC_BASE_URL` 未正确配置，请求打到官方端点 | 常见 |
| [CC-007](/claude-code/errors/cc-401-ide-mcp-conflict) | 401 无效令牌（sk 开头令牌） | IDE 插件或 MCP 服务器覆盖了 settings.json 中的 apiKey / baseURL | 常见 |
| [CC-016](/claude-code/errors/cc-401-leftover-env) | 无效令牌（曾买过第三方服务后切换） | 旧服务遗留的环境变量覆盖了新配置 | ✅ 已解决 |
| [CC-018](/claude-code/errors/cc-oauth-conflict) | 登录过官网后 API Key 失效 | OAuth 令牌写入 `~/.claude.json`，优先级高于 settings.json | ✅ 已解决 |
| [CC-021](/claude-code/errors/cc-invalid-key-format) | 401 Invalid API Key format，Key 目视正确仍报错 | 从 PDF / 网页 / 截图复制 Key 时混入零宽空格、换行符等不可见字符 | 常见 |

## 📦 请求 / 配置类

返回 400 / 413 / Invalid model name / 请求格式异常。**通常是某个 Beta 头或参数不被对端支持**。

| 编号 | 现象 | 根因 | 状态 |
| --- | --- | --- | --- |
| [CC-006](/claude-code/errors/cc-400-experimental-betas) | 请求返回 400，与内容无关 | CC 附加了实验性 Beta 请求头，中转服务不支持 | ✅ 已解决 |
| CC-011 | API Error 400（非内容原因） | CC 本身 bug 导致请求体格式异常，重发或 `/compact` 后通常恢复 | 常见 |
| CC-013 | Command timed out after 2m 0.0s | CC 等待 shell 命令返回超时，与 API 请求无关，可手动执行对应命令 | 常见 |
| [CC-014](/claude-code/errors/cc-413-invalid-model) | 413 请求体过大 / 400 Invalid model name | 上下文超限（413）或 Opus 并发配额不足（400） | 常见 |
| CC-015 | API Error: response exceeded the 32000 | 单次回复超出默认输出 token 上限，设置 `CLAUDE_CODE_MAX_OUTPUT_TOKENS=32000` 解决 | ✅ 已解决 |
| [CC-024](/claude-code/errors/cc-024-third-party-system-role-400) | 第三方 / 国产模型 400 `messages[].role: unknown variant system` | CC 启用 `mid_conversation_system` Beta，第三方端点未跟进，仍只接受 user / assistant 两种 role | ✅ 已解决 |
| CC-003 | 503 model_not_found | 所选模型在当前渠道下线或不可用 | 常见 |
| CC-004 | context window 超限，对话被截断 | 单次会话积累 token 过多，未及时 `/compact` 或新开会话 | 常见 |

## 不知道是哪一类？

按你看到的关键字搜索本页（`Ctrl+F` 或顶部搜索框）：

- 出现 `401` → 认证 / Key 类
- 出现 `429` → 权限 / 速率类
- 出现 `Connection error` / `timed out` → 网络 / 连接类
- 出现 `400 Invalid model name` / `unknown variant` → 请求 / 配置类
- 出现 `Permission denied` / `skipAutoPermissionPrompt` → 权限 / 速率类
- 出现 `pending_messages` / `worker` → claude-mem 类

实在找不到的，先回 [CC Switch 配置](/claude-code/cli/cc-switch) 检查 Base URL / Key / 模型。
