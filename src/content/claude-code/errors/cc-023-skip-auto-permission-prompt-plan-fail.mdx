# CC-023：加入 skipAutoPermissionPrompt 后 Plan 模式无法执行

<ErrorMeta
  component="Claude Code 本体"
  version="旧案例；v2.1.220 官方设置表未列出该字段"
  platform="Windows"
  date="2026-04-13"
/>
---

## 问题现象

旧案例在 `~/.claude/settings.json` 中加入 `"skipAutoPermissionPrompt": true` 后遇到 Plan 模式异常，移除后恢复。本次未能在 Claude Code 当前官方 settings 表中确认该字段，因此不能把该相关性推广为“全版本已确认根因”。

```json
{
  "skipAutoPermissionPrompt": true
}
```

---

## 根因分析

案例中观察到的顺序如下：

```text
settings.json 中加入 "skipAutoPermissionPrompt": true
  → Claude Code 跳过自动权限提示相关流程
  → Plan 模式执行阶段无法继续推进
  → 表现为 Plan 模式不可执行或执行即中断
```

当前只能确认它是来源不明的配置字段。官方 schema 未列出的字段不应作为权限提示或 Plan 模式的通用设置；实际异常仍应通过 `claude doctor`、`/status` 和当前版本日志核对。

---

## 修复步骤

**第一步：打开配置文件**

### macOS / Linux

```bash
cat ~/.claude/settings.json
```

### Windows

```powershell
Get-Content "$env:USERPROFILE\.claude\settings.json"
```

**第二步：删除 `skipAutoPermissionPrompt` 字段**

先备份文件。如果当前配置中存在该字段，删除该键并保留其他配置；不要用重定向命令覆盖整个文件。

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://foropencode.com",
    "ANTHROPIC_API_KEY": "sk-xxx"
  }
}
```

示例中的 `foropencode.com` 是第三方网关，不是 Anthropic 官方端点。

**第三步：重新打开终端并再次进入 Claude Code**

### macOS / Linux

```bash
claude
```

### Windows

```powershell
claude
```

**第四步：再次验证 Plan 模式**

移除该字段后重新进入 Plan 模式，确认流程已可正常执行。

## 预防措施

| 做法 | 避免的问题 |
| --- | --- |
| 仅添加文档中明确标注用途的配置项 | 避免把来源不明的字段写入 `settings.json` 后触发隐藏兼容性问题 |
| 调整权限相关配置后先做一次基础功能验证 | 避免在正式使用时才发现 Plan 模式不可执行 |
| 遇到联网或权限问题时优先对照官方字段名和现有报错文档 | 避免把无关字段误当成通用修复项 |
