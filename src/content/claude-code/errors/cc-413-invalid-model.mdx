# CC-014：413 请求体过大 / 400 Invalid model name

<ErrorMeta
  component="Claude Code 本体"
  version="不限版本"
  platform="Linux / macOS / Windows"
  date="2026-03-14"
/>
---

## 问题现象

**现象 A：**

```text
API Error: 413 Request Entity Too Large
```

**现象 B：**

```text
API Error: 400 Invalid model name
```

两者都发生在请求阶段，但不是同一种错误，也不能仅凭状态码排除网关层限制。

---

## 根因分析

```text
现象 A（413）：
  当前会话上下文 token 数量过多
  → 请求体超过服务端允许的最大体积
  → 返回 413

现象 B（400 Invalid model name）：
  请求中的模型 ID 未被当前端点识别、未开放给该 Key，或协议映射不一致
  → 端点拒绝模型参数
```

---

## 修复步骤

### 现象 A：413 请求体过大

**方式一：清理上下文**

```text
/clear
```

或退出后重新打开 Claude Code 进入新会话。

**方式二：压缩上下文**

```text
/compact
```

保留摘要后继续，避免完全丢失对话记录。

### 现象 B：400 Invalid model name

1. 用 `/status` 核对 Base URL，避免把第三方 Key 发往 Anthropic 官方端点或反过来
2. 用 `/model` 查看客户端实际模型选择，并对照 Anthropic 官方模型清单或第三方网关实时模型列表
3. 检查模型 ID 拼写、访问权限和网关协议映射；不要把“Invalid model”一律解释为 Opus 并发不足

---

## 预防措施

| 做法 | 避免的问题 |
| --- | --- |
| 长任务中定期执行 `/compact` | 上下文堆积触发 413 |
| 模型名只从当前官方清单或网关实时列表复制 | 避免使用过期、猜测或未授权模型 ID |
