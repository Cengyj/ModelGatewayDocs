# CC-005：首次启动即报 Unable to connect to Anthropic services

<ErrorMeta
  component="Claude Code 本体"
  version="v2.1.220 核对"
  platform="Linux / macOS / Windows"
  date="2026-07-26"
/>

---

## 问题现象

Claude Code 安装完成后，第一次执行 `claude` 或登录时显示无法连接 Anthropic 服务：

```text
Unable to connect to Anthropic services
Please check your internet connection and network settings.
```

![Claude Code 首次启动连接错误示例](/img/errors/cc-onboarding-connection-block.webp)

---

## 安全边界

旧版页面把 `~/.claude.json` 中手写 `hasCompletedOnboarding: true` 描述为标准修复。这是内部状态字段，本次未在 [Anthropic 官方安装文档](https://code.claude.com/docs/en/setup) 或 [LLM Gateway 文档](https://code.claude.com/docs/en/llm-gateway-connect) 中确认，因此已撤下。手动标记 onboarding 完成可能跳过必要的登录、地区、条款或连接检查，不应作为通用方案。

---

## 支持的排查顺序

1. 运行 `claude --version`，确认安装完成且来自 Anthropic 官方渠道
2. 打开 [Anthropic 支持地区页面](https://www.anthropic.com/supported-countries)，确认官方服务适用于你的所在地与账户
3. 检查系统时间、DNS、企业防火墙、证书代理和已获授权的系统代理设置
4. 使用官方 Anthropic 账户/API 时，按应用可见的登录流程完成认证
5. 使用受支持的 LLM Gateway 时，只配置官方文档列出的 `ANTHROPIC_BASE_URL`，并根据网关要求选择 `ANTHROPIC_API_KEY`（`x-api-key`）或 `ANTHROPIC_AUTH_TOKEN`（Bearer）
6. 查看 [Anthropic 官方安装文档](https://code.claude.com/docs/en/setup) 与 [LLM Gateway 文档](https://code.claude.com/docs/en/llm-gateway-connect)；仍失败时向 Anthropic 或你实际选择的网关支持渠道反馈完整错误，但不要提交真实 Key

<Callout type="warning" title="不要用内部字段跳过首次引导">
如果官方登录或网关配置仍无法进入会话，停止修改 `~/.claude.json` 的 onboarding 状态。也不要关闭安全软件、TLS 校验或组织访问控制来“验证”是否能连接。
</Callout>
