# CC Switch

<VersionBadge version="v3.18.0" date="2026-07-21" license="MIT" github="https://github.com/farion1231/cc-switch" />

<PageHeader
  useCase="用第三方桌面工具管理多个 AI 客户端的 provider 与密钥配置"
  audience="需要用图形界面管理多个 AI 客户端配置的用户"
  tldr="装 CC Switch → 选工具图标 → 填表单 → 添加"
/>

[CC Switch](https://github.com/farion1231/cc-switch) 是 `farion1231` 维护的第三方社区配置管理器，不是 OpenAI、Anthropic 或其他模型厂商的官方产品。v3.18.0 的官方说明称支持 8 个工具，并包括 Gemini CLI 与 Grok Build；准确客户端清单以当前 [官方仓库 README](https://github.com/farion1231/cc-switch) 为准。

<Callout type="warning" title="使用前先备份并核对数据流">
CC Switch 会读取或写入多个客户端的 provider、Base URL 和 API Key 配置。使用前先备份现有文件，确认最终 API 域名和网关运营方，并只从项目官网 `ccswitch.io` 或仓库 `github.com/farion1231/cc-switch` 获取软件。
</Callout>

## 安装

<Tabs defaultValue="win">
  <Tab label="Windows" value="win">
    到 [farion1231/cc-switch 官方 Releases](https://github.com/farion1231/cc-switch/releases/latest) 选择与 Windows 版本和 CPU 架构匹配的发布资产。核对仓库所有者与发布签名；本站不托管安装包。
  </Tab>
  <Tab label="macOS" value="mac">
    Homebrew Cask（macOS 12 Monterey 及以上）：

    ```bash
    brew install --cask cc-switch
    ```

    或从 [官方 Releases](https://github.com/farion1231/cc-switch/releases/latest) 下载当前 macOS 发布资产。若系统提示发布方或签名异常，停止打开并回到官方仓库核实，不要绕过 Gatekeeper。
  </Tab>
  <Tab label="Linux" value="linux">
    要求 Ubuntu 22.04+ / Debian 11+ / Fedora 34+：

    | 包格式 | 安装方式 |
    | --- | --- |
    | `.deb` | `sudo dpkg -i cc-switch_*.deb` |
    | `.rpm` | `sudo rpm -i cc-switch-*.rpm` |
    | `.AppImage` | `chmod +x cc-switch-*.AppImage && ./cc-switch-*.AppImage` |
    | AUR（Arch） | `paru -S cc-switch-bin` |

    AUR 的 `cc-switch-bin` 由社区维护，不是 farion1231 官方发布渠道；安装前可用 `paru -Gp cc-switch-bin` 查看 PKGBUILD，确认 source 指向 `github.com/farion1231/cc-switch` 官方 Releases。
  </Tab>
</Tabs>

## 模型与网关支持

CC Switch 负责写配置，不决定上游网关真正提供哪些模型。OpenAI/Anthropic 官方模型清单、CC Switch 表单可选项和第三方网关实际能力不能互相替代。配置时应先从网关控制台或模型列表获取当前模型 ID、上下文、输出限制和协议，再按对应客户端官方文档填写。

## 数据位置

| 路径 | 用途 |
| --- | --- |
| `~/.cc-switch/cc-switch.db` | SQLite 数据库，存供应商、MCP、Prompts、Skills |
| `~/.cc-switch/settings.json` | 设备级 UI 偏好 |
| `~/.cc-switch/backups/` | 自动备份，保留最近 10 份 |
| `~/.cc-switch/skills/` | 默认以符号链接同步到各 AI 客户端 |

这些目录可能含 API Key、Token、供应商地址和备份。不要上传到公开仓库或第三方排障网站；卸载前也应按项目官方说明确认是否保留配置。

## 常见问题

<Callout type="warning" title="为什么删不掉当前启用的供应商？">CC Switch 的设计是：**每个工具至少保留一个启用的供应商**，这样即使把 CC Switch 卸载，CLI 工具依然可用。要删它，先切到别的供应商再删。</Callout>

<Callout type="info" title="哪些客户端支持热切换？">README 明确：**Claude Code 支持热切换**，切换后无需重启终端。其它客户端切换后需要重启终端或重启应用。</Callout>
